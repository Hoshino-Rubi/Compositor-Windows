# Compositor for Windows 0.4.1a7 — Native GPU Display and Experimental Editing

**Pre-release only. Stable Latest remains 0.4.0.** Keep backups when testing.

## What's new

- Native Direct3D 11 canvas presentation: GPU composite textures reach the presenter without a synchronous document-image readback. Layer transforms, image masks, clipping, adjustment coverage and folder effects can remain on the GPU; Qt still draws interface overlays.
- GPU implementations for 8/16-bit paint, eraser, clone, blur brush, all three healing modes and perspective sampling. Editing preserves selections, metadata and undo, with CPU fallback on unavailable hardware or insufficient resources.
- **Experimental GPU editing is off by default**, under Preferences → General. It controls those new editing paths, including perspective, because the measured workloads are slower than the CPU reference. Existing GPU filters/liquify, native display and the separate export renderer choice are unaffected.
- Export As offers **Reference CPU (default)** and **Accelerated GPU**. Large uniform-scale local operations can render in tiles; large global-coordinate adjustments and nonuniform tiled resizing use CPU fallback. PNG remains 8/16-bit; JPEG and raster PDF remain 8-bit. Encoding is CPU-side.
- Eight complete interface languages; no new runtime dependency or project-format change.

## Fidelity and remaining CPU work

This is not an entirely GPU-resident or Metal-equivalent pipeline. Brush-tip/selection geometry, shape rasterization, text layout, analysis and encoding still use CPU code. Perspective prepares geometric coverage on the CPU using a constant white texel, then uploads row bounds; source-image sampling and interpolation run on the GPU. Image-edit operations and export still read back their output synchronously.

Atkinson/Floyd–Steinberg error diffusion and Camera Raw with active luminance denoising retain their performance-validated CPU routing. `COMPOSITOR_DISABLE_GPU=1` selects CPU processing. A presentation failure falls back to QWidget rendering for that canvas instance.

GPU and Qt resampling are not pixel-identical. Tests bound numerical differences and check transparency/geometry separately. Qt's 8-bit affine SIMD interpolation uses coarse weights; one mask-edge fixture differs by five native levels while the GPU matches the independent high-precision reference. Earlier effect-edge limitations still apply. Default CPU export does not silently change rendering policy.

## Validation and performance

Native Release and extracted-portable validation each cover eight Qt Test suites: **186 passes, one optional external HEIC-alpha fixture skipped, zero failures** (pass counts include initialization/cleanup). GPU tests require a real D3D11 adapter and check dispatch/readback behavior, not a silent CPU fallback. Hidden-window presenter tests verify actual pixels, UV cropping, immutable textures and resize. This is automated validation, not an interactive multi-device certification.

Local warm medians of three runs; initial shader compilation excluded. Timings include the respective operation's preparation, transfers and readback, but not UI presentation. These are workload-specific measurements, **not speedup claims**:

## 0.4.1a7 — 原生 GPU 显示与实验性编辑

**仅预发布，稳定版 Latest 保持 0.4.0。**测试前请保留备份。

### 新增

- 原生 Direct3D 11 画布显示：GPU 合成纹理直接交给显示器，不必同步回读文档图像；图层变换、图像蒙版、剪贴、调整覆盖和文件夹效果可在 GPU 处理，界面覆盖层仍由 Qt 绘制。
- 新增 8／16 位画笔、橡皮、克隆、模糊笔刷、三种图像修复及透视采样 GPU 实现，保留选区、元数据与撤销；设备不可用或资源不足时回退 CPU。
- **首选项 → 常规中的“实验性 GPU 编辑”默认关闭**，控制上述新编辑路径，包括透视。原因是实测样本比 CPU 慢；现有 GPU 滤镜／液化、原生显示和独立导出选项不受影响。
- “导出为”提供默认的参考 CPU 和可选 GPU 渲染。较大等比局部操作可分块；较大全局坐标调整、非等比分块缩放回退 CPU。PNG 保留 8／16 位，JPEG 与栅格 PDF 为 8 位；编码仍在 CPU。
- 八种完整界面语言，无新增运行时依赖或项目格式变化。

### 边界与验证

不是全 GPU 驻留或完整 Metal 等效管线。笔尖／选区几何、形状栅格化、文字排版、分析与编码仍使用 CPU。透视只用常量白色像素在 CPU 准备几何覆盖与行边界，文档图像采样和插值在 GPU；编辑结果及导出仍需同步回读。

Atkinson／Floyd–Steinberg 误差扩散和启用亮度降噪的 Camera Raw 保留经性能验证的 CPU 路由。`COMPOSITOR_DISABLE_GPU=1` 选择 CPU；显示失败后该画布实例回退 QWidget。

GPU 与 Qt 插值并非逐像素相同。测试分别验证几何／透明边界及数值误差；Qt 的 8 位仿射 SIMD 使用较粗权重，一项蒙版边缘样本相差五个通道单位，但 GPU 符合独立高精度参考。此前的效果边缘差异仍存在；默认 CPU 导出不改变原渲染策略。

原生 Release 与解压便携包各运行八套 Qt Test：**186 项通过、1 项需要外部 HEIC-alpha 样本的测试跳过、0 失败**，通过数包含初始化／清理。GPU 测试强制真实 D3D11 路径；隐藏窗口显示测试检查实际像素、裁切、纹理不可变性与调整大小。这是自动化验证，不代表多设备交互认证。

上表为本机三次预热中位数，排除首次 shader 编译，包含操作准备、传输与回读，不含界面显示。新增编辑样本目前较慢，因此开关默认关闭；不承诺普遍提速。

下载 ZIP 后完整解压，运行 `Compositor.exe`，保留全部 DLL、插件、模型与许可证。支持 Windows 10／11 x64，无需 Qt SDK、Python、Node.js 或浏览器运行时；附带 SHA-256 校验文件。
