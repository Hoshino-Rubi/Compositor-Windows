# Compositor for Windows 0.4.1a5p1 — Sequential Filter Performance Fix

**Pre-release patch for 0.4.1a5. Stable Latest remains 0.4.0.**

## Fixed

- **Atkinson / Floyd–Steinberg dithering:** use the CPU reference implementation instead of serial GPU passes. All palettes, pixel sizes and 8/16-bit document workflows remain available; the other eight Dither styles keep their GPU paths.
- **Camera Raw luminance denoising:** when active, the entire Camera Raw request uses the CPU reference pipeline. This avoids the slow serial GPU stage and additional mid-pipeline readback/upload, and preserves reference output. It is intentional CPU routing, not a new GPU acceleration algorithm.
- **GPU processing remains available** for Camera Raw without active luminance denoising, disabled Detail, temporary clipping previews and sharpening-mask previews, as well as the other a5 adjustments, blend modes, effects and filters.
- Backend selection occurs before GPU initialization, image upload or cache eviction. Preview and Apply use the same policy; selections and undo/redo remain intact. No new preference, runtime dependency or project-format change.

## Validation

Native and extracted-portable Qt Test runs: **127 passed, 0 failed, 1 skipped** (the optional HEIC-alpha fixture was not supplied). Added reference-pixel and zero-GPU-dispatch checks for both sequential filters, plus 8/16-bit selection/undo/redo and Camera Raw bypass-mode coverage. Retained GPU paths are checked for actual compute dispatches. Performance fixtures cover 512×384 and 1024×768 images.

Local warm-run medians of three repetitions at **512×384**, including the complete processing call:

| Operation | Bit depth | CPU reference | Automatic routing (CPU) |
|---|---:|---:|---:|
| Camera Raw + luminance denoising | 8 | 62.8 ms | 60.2 ms |
| Atkinson (original colors) | 8 | 19.6 ms | 20.8 ms |
| Floyd–Steinberg (original colors) | 8 | 19.5 ms | 19.8 ms |
| Camera Raw + luminance denoising | 16 | 89.6 ms | 90.8 ms |
| Atkinson (original colors) | 16 | 34.8 ms | 34.9 ms |
| Floyd–Steinberg (original colors) | 16 | 32.9 ms | 33.4 ms |

These requests now perform **zero GPU processing dispatches/readbacks** and match the CPU reference exactly in the fixtures. Timings depend on hardware and system load; this is a routing fix, not a claim that the CPU algorithm itself became faster.

## Remaining limitations

This patch does not make the editor entirely GPU-based or promise universal speedups. Existing a5 geometric resampling/stroke antialiasing differences, synchronous readback and resource limits remain for GPU-backed operations. Requests over 8MP or the available resource budget use CPU fallback; adjustment Hard Mix requires hardware FP64. Export remains CPU-backed. `COMPOSITOR_DISABLE_GPU=1` selects the reference path globally.

## Download

Extract `Compositor-0.4.1a5p1-win-x64.zip` and run `Compositor.exe`; keep its DLLs, plugins, models and licenses together. Windows 10/11 x64. No Qt SDK, Python, Node.js or browser runtime is required. The `.sha256` asset verifies the archive.

## 0.4.1a5p1 — 顺序滤镜性能修复

**0.4.1a5 的预发布补丁；稳定版 Latest 保持 0.4.0。**

### 修复

- **Atkinson／Floyd–Steinberg 抖动：**使用 CPU 参考实现替代串行 GPU 调度，保留全部配色、像素大小和 8／16 位文档工作流；其他八种抖动样式继续使用 GPU。
- **Camera Raw 亮度降噪：**实际启用时，整次 Camera Raw 请求使用 CPU 参考管线，避免缓慢的串行 GPU 阶段以及中间回读／上传，保留参考结果。这是有意选择 CPU，并非新的 GPU 加速算法。
- **保留 GPU 路径：**未实际启用亮度降噪、关闭“细节”、临时剪切预览和锐化蒙版预览，以及 a5 的其他调整层、混合模式、图层效果与滤镜。
- 在 GPU 初始化、图像上传和缓存淘汰之前选择后端。预览和应用使用同一策略，保留选区与撤销／重做；没有新增首选项、运行时依赖或项目格式变更。

### 验证

原生构建与解压后便携包的 Qt Test 均为 **127 项通过、0 项失败、1 项跳过**（未提供可选 HEIC-alpha 测试样本）。新增两类顺序滤镜的参考像素一致性／零 GPU 调度验证，以及 8／16 位选区、撤销／重做和 Camera Raw 跳过降噪的模式覆盖；保留的 GPU 路径验证实际计算调度。性能样本覆盖 512×384 与 1024×768。

本机 **512×384** 预热后重复三次的中位数，计入完整处理调用：

| 操作 | 位深 | CPU 参考路径 | 自动路由（CPU） |
|---|---:|---:|---:|
| Camera Raw＋亮度降噪 | 8 | 62.8 ms | 60.2 ms |
| Atkinson（原色） | 8 | 19.6 ms | 20.8 ms |
| Floyd–Steinberg（原色） | 8 | 19.5 ms | 19.8 ms |
| Camera Raw＋亮度降噪 | 16 | 89.6 ms | 90.8 ms |
| Atkinson（原色） | 16 | 34.8 ms | 34.9 ms |
| Floyd–Steinberg（原色） | 16 | 32.9 ms | 33.4 ms |

上述请求的 **GPU 处理调度／回读均为零**，测试样本与 CPU 参考结果完全一致。计时取决于硬件和系统负载；修复的是后端选择，不是宣称 CPU 算法本身变快。

### 仍然存在的限制

此补丁不代表全编辑器 GPU 化，也不承诺所有操作提速。GPU 操作仍存在 a5 已说明的几何重采样／描边抗锯齿差异、同步回读及资源限制；超过 8MP 或资源预算时回退 CPU，调整层 Hard Mix 要求硬件双精度。导出仍使用 CPU。`COMPOSITOR_DISABLE_GPU=1` 可全局选择 CPU 参考路径。

### 下载

解压 `Compositor-0.4.1a5p1-win-x64.zip`，运行 `Compositor.exe`，保留 DLL、插件、模型和许可证。支持 Windows 10／11 x64，无需另装 Qt SDK、Python、Node.js 或浏览器运行时。可使用 `.sha256` 校验压缩包。
