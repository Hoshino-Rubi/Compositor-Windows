# Compositor for Windows 0.4.1a5 — GPU Filters, Effects and Camera Raw

**Pre-release · Windows 10/11 x64 · native Qt 6.** Fifth GPU-pipeline batch. Stable Latest remains **0.4.0**. Back up projects before testing.

## What's new

- **Seven more GPU adjustments:** Hue/Saturation (ranges, inversion and colorize), Black & White, Color Balance, Gradient Map, Add Noise, Grain and Motion Blur, at native 8/16-bit depth.
- **All 24 adjustment blend modes.** Invert, Exposure, Levels, Curves and Gaussian Blur are no longer limited to Normal; the seven new adjustments use the same blend/mask/opacity pipeline.
- **GPU layer effects:** outside/inside Stroke, Drop Shadow, Inner Shadow, Outer/Inner Glow and Color Overlay. Includes folder effects, masks, clipping, opacity, canvas previews and the effects dialog.
- **Camera Raw pixel processing:** light/color/calibration, curves, mixer and point color, grading, texture, clarity, dehaze, glow, grain, vignette, lens/profile correction, defringe/chromatic correction, perspective/geometry, luminance/chroma denoising, sharpening and temporary clipping/sharpen-mask overlays.
- **GPU standalone filters:** Vignette, Bloom / Glow, Tonal Contrast, Lens Correction and Scanlines (displacement, beads, wobble, color split and glow); all ten Dither styles, including ordered/error-diffusion, halftone, patterns and glyphs.
- Filter previews, destructive filter application and Camera Raw preview/apply use Direct3D 11 when hardware and memory permit. Selection constraints and undo remain intact. The existing four tone filters also use the full native-depth lookup-table path when applied directly.

## Scope, precision and performance

This completes GPU implementations for this batch's listed image-processing stages, **not the entire editor and not pixel-identical CPU rendering**. Source/mask preparation, small parameter/LUT/font-atlas generation, aggregation of reduced GPU statistics, UI analysis, brushes/retouch and export remain CPU-backed. GPU readback is synchronous. The scratch pool is capped at 256 MiB within the overall resource budget; image requests above 8MP, unsupported devices and resource failures fall back to CPU. Adjustment Hard Mix requires hardware double-precision shader support.

GPU/Qt resampling and stroke antialiasing differ. Tests bound geometric interpolation separately from color arithmetic; isolated inner-stroke corner samples can differ by approximately 5% because the GPU integrates a union rather than Qt's overlapping path coverage. Small color-rounding differences can flip Hard Mix or error-diffusion thresholds. Live-effect exports use the CPU reference renderer and can therefore differ at these edges; destructive GPU edits save their actual computed pixels. Set `COMPOSITOR_DISABLE_GPU=1` for the reference path.

**GPU does not always mean faster.** In one local warm-shader 512×384 run (upload, scratch allocation and readback included): Scanlines took about **3.0–3.2 ms GPU vs 13.8–18.8 ms CPU**; Motion Blur **2.4 ms vs 5.0–5.8 ms**. Camera Raw with sequential luminance denoising took **about 200 ms GPU vs 63–125 ms CPU**, and Atkinson original-color diffusion **138–139 ms vs about 20 ms**. Ordered dependencies are kept deterministic using bounded sequential GPU passes; optimizing those costs remains future work. These are workload-specific timings, not universal speedup claims.

## Validation and compatibility

Automated hardware tests cover both depths; all twelve adjustments and 24 blend modes; 27 Camera Raw control combinations plus temporary clipping; ten dither styles and palettes; scanlines; motion/geometry; translucent, holed and grouped effects; cache reuse; destructive edits/undo; dialog cancellation; and CPU fallback. Native and extracted-portable regression results are verified before publishing. Eight interface catalogs are retained. No project-format or runtime-dependency changes.

Extract `Compositor-0.4.1a5-win-x64.zip` and run `Compositor.exe`; keep its DLLs, plugins, models and licenses together. The `.sha256` asset verifies the archive. No Qt SDK, Python, Node.js or browser runtime is required. **Pre-release only; stable Latest stays 0.4.0.**

## Compositor Windows 0.4.1a5 — GPU 滤镜、图层效果与 Camera Raw

**预发布 · Windows 10/11 x64 · 原生 Qt 6。** GPU 管线第五批，稳定版 Latest 保持 **0.4.0**。请先备份项目。

### 新增内容

- **七类 GPU 调整：**色相／饱和度（含范围、反向及着色）、黑白、色彩平衡、渐变映射、添加杂色、颗粒、动态模糊，支持原生 8／16 位。
- **24 种调整层混合模式：**原有反相、曝光、色阶、曲线、高斯模糊不再只支持 Normal；七类新调整共用混合、蒙版和不透明度管线。
- **GPU 图层效果：**内／外描边、投影、内阴影、内／外发光、颜色叠加；涵盖组效果、蒙版、剪贴、不透明度、画布及效果对话框预览。
- **Camera Raw 图像处理：**光线／颜色／校准、曲线、混色与点颜色、分级、纹理、清晰度、去朦胧、辉光、颗粒、暗角、镜头／配置校正、去边／色差校正、透视／几何、亮度／色彩降噪、锐化、临时剪切及锐化蒙版预览。
- **GPU 独立滤镜：**暗角、Bloom、色调对比、镜头校正、扫描线（含位移、点状、波动、色彩分离及辉光）；十种抖动样式，包括有序／误差扩散、半色调、图案与字符。
- 滤镜预览、直接应用以及 Camera Raw 预览／应用均接入 Direct3D 11，保留选区约束及撤销。直接应用原有四类色调滤镜也使用完整位深查找表。

### 范围、精度与性能

本批所列图像处理阶段均已有 GPU 实现，**不等于整个编辑器全部 GPU 化，也不保证与 CPU 逐像素一致**。源图／蒙版准备、小型参数／查找表／字体图集生成、GPU 归约统计汇总、界面分析、画笔／修复和导出仍用 CPU。GPU 需要同步回读；临时纹理池上限为 256 MiB，并计入整体资源预算。超过 8MP、不支持的设备或资源不足回退 CPU；调整层 Hard Mix 要求硬件双精度着色器。

GPU 与 Qt 的重采样、描边抗锯齿不同。测试对几何插值与色彩运算分别限制误差；GPU 计算几何并集，而 Qt 部分重叠描边路径累计覆盖率，因此少量内描边角点样本可能有约 5% 差异。微小舍入差异也可能改变 Hard Mix 或误差扩散阈值。实时效果导出使用 CPU 参考渲染器，在这些边缘可能不同；直接 GPU 编辑保存实际处理后的像素。设置 `COMPOSITOR_DISABLE_GPU=1` 可使用 CPU 参考路径。

**GPU 并非总是更快。** 一次本机 512×384、着色器预热后的测试（含上传、临时纹理分配与回读）：扫描线约 **GPU 3.0–3.2 ms / CPU 13.8–18.8 ms**；动态模糊约 **2.4 ms / 5.0–5.8 ms**。含顺序亮度降噪的 Camera Raw 约 **200 ms / 63–125 ms**；原色 Atkinson 扩散约 **138–139 ms / 20 ms**。为保持顺序依赖，使用有界的顺序 GPU 批次；这两类成本还需后续优化。这些数字只代表对应场景，不承诺普遍提速。

### 验证与兼容性

硬件测试涵盖两种位深、十二类调整与 24 种混合、27 组 Camera Raw 控件组合及临时剪切、十种抖动及配色、扫描线、动态模糊／几何、半透明／孔洞／组效果、缓存复用、直接编辑与撤销、对话框取消、CPU 回退。发布前验证原生和解压便携包的回归结果。保留八种界面语言，不修改项目格式，不增加运行时依赖。

解压 `Compositor-0.4.1a5-win-x64.zip` 后运行 `Compositor.exe`，保留 DLL、插件、模型及许可证；`.sha256` 用于校验压缩包。无需 Qt SDK、Python、Node.js 或浏览器运行时。**仅预发布，稳定版 Latest 保持 0.4.0。**
