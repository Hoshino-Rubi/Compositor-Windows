# Compositor for Windows 0.4.1a4 — GPU Tone Adjustments

**Pre-release · Windows 10/11 x64 · native Qt 6.** Fourth incremental GPU-pipeline batch. Stable Latest remains **0.4.0**. Back up projects before testing an alpha.

## What's new

- **GPU Invert, Exposure, Levels and Curves adjustment previews**, in Normal blend mode and native 8/16-bit depth. Works in adjustment dialogs and with raster layers, Gaussian Blur adjustments, masks, clipping and folder opacity.
- Complete per-channel tables retain **all 65,536 native input values in 16-bit mode** (256 in 8-bit). The CPU reference generates each table; Direct3D 11 applies it to image pixels, including alpha and mask coverage. Cached alpha factors match Qt's native unpremultiplication behavior.
- Parameter changes update only the adjustment table, without reuploading the source image or reallocating warm textures. Pixel, mask and opacity edits reuse tables. Identical requests skip processing and readback.
- Tone-only stacks retain **dirty-rectangle recomposition/readback**. Setting/order changes recompose the requested viewport; visible Gaussian Blur retains a3's full-region dependency handling and tile halos. Lookup and alpha tables count toward the existing cache budget.

## Scope and compatibility

Only Normal-blend Invert, Exposure, Levels, Curves and Gaussian Blur adjustments are GPU-backed. Other adjustment types, non-Normal adjustments and live layer effects use the CPU renderer, as do unsupported hardware/resource/budget cases. Lookup-table generation, source/mask preparation, destructive filters, brush/retouch kernels, Camera Raw and export remain CPU-backed. Parameter changes can still spend CPU time generating a 16-bit table, especially curves. Changed frames still require synchronous readback; this is not zero-copy display or a complete GPU editing pipeline.

The `.comp` format, saved/exported pixels, eight interface languages and runtime dependencies are unchanged. GPU/CPU results are not guaranteed identical for every complex blended stack or device. This batch is **pre-release only**; it does not replace stable Latest.

## Validation

Native and extracted portable suites: **111 passed, 0 failed, 1 optional HEIC-alpha fixture skipped**. Single-adjustment 8/16-bit sample and transparency fixtures match the CPU reference exactly; complex stacks, masks, tiles, partial updates, undo/redo, dialog cancellation and CPU fallback are covered. The portable executable is byte-identical to the tested build; all eight language catalogs were checked.

Local 1024×1024 Exposure-preview workload, six parameter changes, warm shaders/source cache: 8-bit CPU **6845.976 ms → GPU 14.057 ms**; 16-bit **7390.077 ms → 550.966 ms**. GPU timings include six complete CPU lookup-table builds/uploads and readbacks; initial setup is excluded. All frames were checked against CPU within one 8-bit step / two 16-bit steps. This is one workload, not a universal speedup or direct a3 comparison.

## Download

Extract `Compositor-0.4.1a4-win-x64.zip` and run `Compositor.exe`. Keep the bundled DLLs, plugins, models and licenses together. The `.sha256` asset verifies the archive. No Qt SDK, Python, Node.js or browser runtime is required.

**预发布 · Windows 10/11 x64 · 原生 Qt 6。** GPU 管线分批迁移的第四批，稳定版 Latest 仍为 **0.4.0**。测试 Alpha 前请备份项目。

### 新增内容

- **反相、曝光、色阶、曲线调整层的 GPU 预览**，支持 Normal（正常）混合及原生 8／16 位精度；适用于调整对话框，并支持与普通图层、高斯模糊、蒙版、剪贴来源和组不透明度叠加。
- 16 位查找表保留 **65,536 个原生输入值**，8 位为 256 项。CPU 参考算法生成逐通道表，Direct3D 11 对图像逐像素应用，包括 Alpha 和蒙版覆盖率；缓存的 Alpha 系数对齐 Qt 原生反预乘行为。
- 修改参数只更新调整表，不重新上传源图或分配热缓存纹理；修改像素、蒙版、不透明度时复用表；相同请求跳过计算与回读。

### 范围与兼容性

GPU 调整仅覆盖 Normal 混合的反相、曝光、色阶、曲线和高斯模糊；其他调整类型、非 Normal 调整、实时图层效果及不支持的硬件／资源／预算情况均回退 CPU。查找表生成、源图／蒙版准备、直接修改像素的滤镜、画笔／修复、Camera Raw 和导出仍由 CPU 处理。修改 16 位参数仍有生成查找表的 CPU 成本，尤其是曲线。变化帧仍需同步回读，不是零拷贝显示，也不是完整 GPU 编辑管线。

项目格式、保存／导出像素、八种界面语言及运行时依赖不变；不保证任意复杂混合叠层或设备的 GPU／CPU 输出完全相同。本批**仅为预发布**，不替换稳定版 Latest。

### 验证

原生和解压后的便携包测试均为 **111 项通过、0 失败、1 项可选 HEIC Alpha 样本测试跳过**。单调整层的 8／16 位样本与透明度用例逐像素匹配 CPU 参考结果；另覆盖复杂叠层、蒙版、分块、局部更新、撤销／重做、对话框取消和 CPU 回退。便携包可执行文件与受测构建字节一致，八种语言目录均已检查。

本机 1024×1024 曝光预览、连续六次参数修改、预热着色器和源缓存：8 位 CPU **6845.976 ms → GPU 14.057 ms**，16 位 **7390.077 ms → 550.966 ms**。GPU 计时包含六次完整 CPU 查找表生成／上传及回读，不含首次初始化；每帧与 CPU 比较，误差限制为一个 8 位阶值／两个 16 位阶值。这仅代表该测试场景，不承诺普遍提速，也不是与 a3 的直接对比。
