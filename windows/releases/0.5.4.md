# Compositor for Windows 0.5.4 — Upstream Integration and Layer Workflows

**Stable release.** Native C++20 / Qt 6 Widgets for Windows 10/11 x64.

Merged **46 upstream commits** through `551a35fc06fb8429fed3b99b175e31681875f580` (October 22, 2026 UTC), including Compositor 1.5.5 and subsequent layer-search/zoom fixes.

- Search layers by name and filter by type or selection; matching folders include their contents, and parents remain visible for context.
- Progressive Blur, Bloom / Glow and RGB Split are editable adjustment layers. RGB Split also has a standalone Linear/Radial spectral filter with streak controls. New filter layers use the reference CPU path, retain 8/16-bit/HDR precision and support masks/blend modes; large spectral effects can be slow.
- Line shapes offer Solid, Dotted, Dashed and Long Dash styles with Square/Round caps. Pixel-aligned one-pixel lines and dots, shared preview/final geometry, and upstream-compatible line metadata.
- Export As offers Channel Pack: choose a layer/group or black/white for each RGBA channel. RGB is retained even where packed alpha is zero. Image → Split Channels produces four grayscale layers with undo and native precision.
- Photoshop artboards open in separate tabs at their own bounds. Font family autocomplete now searches within names. Image Size/Canvas Size preserve zoom, and automatic image fitting does not enlarge past 100%.
- Reads upstream v15/v16 projects and legacy Windows 16-bit masks. New native high-depth-mask saves use Windows **v17**, avoiding the upstream v15 line-style version. Compatibility mode writes upstream v11–v16 as required, with standard 8-bit masks plus lossless 16-bit sidecars for Windows reopening.
- New interface text is translated in all eight languages. No new runtime dependency.

**Scope:** this merge does not claim complete new macOS UI parity. Multi-page PDF import, tablet pressure controls, physical-key shortcuts on non-Latin layouts, the macOS per-face font panel and RGB Split's separate dispersed-color-layer action are not ported in this release. The standalone RGB Split works within existing raster bounds; the adjustment layer processes the canvas. Existing RAW engine, object-selection, font-rendering and GPU/Metal differences remain. The app/updater are unsigned.

## Upgrade and compatibility

Use **Help → Check for Updates → Install and Restart**, or extract the complete `Compositor-0.5.4-win-x64.zip`. Keep its DLLs, plugins, models, translations and licenses together. The normal 0.5.4 version is recognized by the previous stable version checker; the special manual-upgrade caveat for the old p1 suffix does not apply to this release.

For a macOS round trip, enable **Compatibility mode** in Save As and use an upstream version supporting the project's features. Keep the entire `.comp` directory to retain the Windows 16-bit mask sidecars. An upstream re-save can discard unknown extension data; retain an original copy when exact 16-bit values matter.

## Verification

All **12 native test suites passed: 281 test results passed, 8 optional skips, zero failures**. Skips are seven opt-in performance reports and the unavailable external HEIC-alpha fixture. Regression coverage includes v15/v16 loading, legacy/new/compatible 16-bit masks, filter-layer render/save/reopen, spectral precision/HDR, transparent channel-packed PNG data, line geometry, layer search, actual PSD artboard parsing, split-channel undo/clipping safety and the new native controls. Existing import, RAW, GPU reference, updater and interaction suites remain covered. No all-device or macOS runtime certification is claimed.

## 0.5.4 — 上游整合与图层工作流

**正式版**，原生 C++20 / Qt 6 Widgets，支持 Windows 10/11 x64。

合并上游 **46 个提交**，截至 `551a35fc06fb8429fed3b99b175e31681875f580`（UTC 2026 年 10 月 22 日），包含 Compositor 1.5.5 及后续图层搜索／缩放修复。

- 按名称搜索图层，按类型或已选中状态筛选；匹配的文件夹包含其内容，并保留父级上下文。
- 渐进模糊、泛光／辉光和 RGB 色散支持可编辑调整层；RGB 色散也提供线性／径向及拖影控制的独立滤镜。新增调整层使用 CPU 参考路径，保留 8/16 位／HDR 精度，支持蒙版及混合模式；大范围光谱效果可能较慢。
- 线条形状支持实线、点线、虚线、长虚线以及方形／圆形端点。预览与最终绘制共用几何，改善单像素线条及点线，并保存上游兼容的线条元数据。
- “导出为”新增通道打包，每个 RGBA 通道可选择图层／组或纯黑／白；Alpha 为零时仍保留 RGB。“图像 → 拆分通道”生成四个灰度图层，保留原生精度并支持撤销。
- Photoshop 画板按自身边界分别打开为标签页；字体家族补全支持名称中间匹配。图像大小／画布大小操作保持缩放，自动适应导入图片不超过 100%。
- 读取上游 v15/v16 项目及旧 Windows 16 位蒙版。新的原生高精度蒙版保存为 Windows **v17**，避免与上游 v15 线条样式混用。兼容模式按所用功能写入上游 v11–v16，标准蒙版为 8 位，另存无损 16 位副本供 Windows 重开。
- 新增界面文案覆盖八种语言，无新增运行时依赖。

**范围：**本次不宣称已完整移植新的 macOS 交互。多页 PDF 导入、数位笔压感控件、非拉丁键盘布局的物理键快捷键、macOS 的逐字体字面列表以及 RGB 色散的独立分色图层动作尚未移植。独立 RGB 色散在现有栅格边界内处理，调整层处理整个画布。RAW 引擎、对象选择、字体渲染及 GPU／Metal 差异仍存在；主程序及更新助手仍未签名。

### 升级与兼容性

使用“帮助 → 检查更新 → 安装并重启”，或下载并完整解压 `Compositor-0.5.4-win-x64.zip`。保留随附的 DLL、插件、模型、翻译及许可证。0.5.4 是旧正式版更新器可以识别的普通版本号，不受之前 p1 后缀需手动升级的限制。

全部 **12 个原生测试套件通过：281 项测试结果通过、8 项可选跳过、0 失败**。跳过的是 7 项需主动启用的性能报告及缺少外部样本的 HEIC-alpha 测试。回归覆盖 v15/v16 读取、旧版／新版／兼容模式的 16 位蒙版、新调整层渲染与保存重开、光谱处理精度／HDR、透明通道打包 PNG、线条几何、图层搜索、实际 PSD 画板文件解析、通道拆分撤销／剪贴关系保护及新增原生控件，并继续运行现有导入、RAW、GPU 参考、更新器与交互套件。不宣称已验证所有硬件或 macOS 运行时。

便携包与镜头依赖源码包均提供 SHA-256 校验文件。镜头依赖源码／构建配方沿用上一版本，运行时不需要源码包。
