# Compositor for Windows 0.5.1 — Upstream 1.5.3 Integration

**Stable release. Replaces 0.5.0 as Latest.** Windows 10/11 x64, native C++20 / Qt 6 Widgets.

## Upstream merge

Merged all **58 commits** after `3081719d5178b466214860fe5fcf5691394dc558` through **`365b5745eda537f984f3d5bed1e53c361dbc9c91`**, upstream Compositor **1.5.3** (October 15, 2026 UTC). Original commit history is preserved, together with the Windows-specific renderer, precision and localization work.

## Windows changes

- **Content-Aware healing and fill:** replace the old single-patch/frontier methods with upstream multi-scale PatchMatch. Both 8-bit and native 16-bit images are supported. The high-depth port retains continuous fractional samples in its floating-point workspace, rather than converting the image to 8-bit. Byte coverage masks, opacity, outside pixels and undo remain protected.
- **Adaptive Camera Raw Shadows:** incorporate upstream coefficients and its region-aware spatial pass between the correct color stages. Both native depths retain their precision. Requests containing active Shadows use the reference CPU pipeline, including clipping previews; the old brightness-table GPU approximation is not silently substituted. Other verified GPU routes and the CPU routing policy from 0.5.0 remain unchanged.
- **Section reset:** reset individual Camera Raw sections without resetting unrelated adjustments; section visibility, point-color selection and geometry guides are refreshed consistently.
- **Folder import:** File → Import image folder enumerates supported files in the chosen directory in filename order, without recursing or treating `.comp` packages as image folders. Existing RAW dialogs and layered PSD workflows remain in effect. New folder messages are translated in eight languages.
- **Project compatibility:** load supported PNG-based v12–v14 projects, including upstream files without a `bitDepth` field. PNG depth determines whether the native document needs 16-bit working pixels; unchanged encoded PNG assets remain preserved. Unsupported HDR/EXR assets and smoothed-corner shapes fail explicitly instead of losing rendering data. Save formats remain v11 for 8-bit and v12 for 16-bit Windows documents.
- Updated the upstream application icon and all displayed/package version metadata to **0.5.1**. HIF/HEIF import, native 16-bit editing and the existing validated preview/retouch optimizations remain available.

## Verification

Native Release and independently extracted portable builds each: **218 passed, one optional external HEIC-alpha fixture skipped, zero failed** across ten Qt Test suites, including initialization/cleanup. The new upstream suite checks PNG project depth inference and byte-preserving round trips, explicit unsupported-feature rejection, PatchMatch determinism/coverage/native precision, adaptive Shadows against the upstream fixed-seed landscape and its original tolerances, real dialog section reset and folder enumeration. Existing rendering, GPU routing, selections/undo and update regressions pass. Portable tests use only bundled/system runtime paths; test-only binaries and plugins are added to the validation extraction, not shipped in the archive. All eight catalogs have matching 623-key sets.

## Scope and compatibility

A full source merge is not a claim that every macOS feature is now implemented on Windows. This patch does **not** add HDR/EXR, CMYK proofing/import/export, Progressive Blur, Gaussian Preserve Transparency, smooth rectangle corners, the new macOS RAW-develop controls or native-resolution/Metal Camera Raw previews. The native Windows preview architecture remains independent. Native 16-bit grayscale masks are a Windows extension; upstream macOS still accepts only 8-bit PNG masks.

The application remains **unsigned**, because no signing certificate was supplied. Update downloads verify size/SHA-256 but installation remains manual. Existing GPU/Qt/Metal pixel differences and large-image/resource limitations remain; no multi-device manual certification or universal performance improvement is claimed.

## Download

Extract `Compositor-0.5.1-win-x64.zip` into a new folder and run `Compositor.exe`. Keep all bundled DLLs, plugins, models and licenses together. No Qt SDK, Python, Node.js or browser runtime is required. The matching `.sha256` asset verifies the archive. Keep project backups when moving between versions/platforms.

## 0.5.1 — 同步上游 1.5.3

**正式版，取代 0.5.0 成为 Latest。** 支持 Windows 10／11 x64，原生 C++20／Qt 6 Widgets。

### 上游合并

完整合并从 `3081719d5178b466214860fe5fcf5691394dc558` 之后到 **`365b5745eda537f984f3d5bed1e53c361dbc9c91`** 的 **58 个提交**，对应上游 **Compositor 1.5.3**（UTC 2026 年 10 月 15 日）。保留原始提交历史，以及 Windows 渲染、位深和国际化改动。

### Windows 改动

- **内容识别修复／填充：**使用上游多尺度 PatchMatch 替换旧算法，支持 8／16 位。16 位浮点工作区保留细分值，不将图像先降为 8 位；保留覆盖蒙版、透明度、范围外像素和撤销。
- **Camera Raw 自适应阴影：**接入新系数和区域自适应处理，并放在正确的颜色阶段之间。两种位深均保留原生精度；启用阴影时包括剪切预览在内整次请求使用 CPU，不用旧 GPU 查找表冒充新算法。其余经验证的 GPU 路线和 0.5.0 的 CPU 分流策略保持不变。
- **分区重置：**Camera Raw 各分区可独立重置，不影响其他调整；同步恢复分区可见性、点颜色选择和几何参考线。
- **文件夹导入：**文件菜单新增导入图像文件夹，按文件名顺序读取所选目录，不递归、不把 `.comp` 当图片文件夹；RAW 对话框及分层 PSD 仍走原有流程。新文案覆盖八种语言。
- **项目兼容：**读取支持范围内的 v12–v14 PNG 项目，包括未写入 `bitDepth` 的原版项目；从 PNG 识别位深，必要时提升为 16 位工作文档，保留未修改的 PNG 原始字节。HDR／EXR 和平滑圆角形状会明确报错，不静默丢失渲染数据。Windows 保存仍为 8 位 v11、16 位 v12。
- 同步上游应用图标，程序与安装包版本统一为 **0.5.1**；已有 HIF／HEIF、原生 16 位及预览／修饰优化保留。

### 验证

原生 Release 与独立解压的便携包各自十套 Qt Test：**218 项通过、1 项可选外部 HEIC-alpha 样本测试跳过、0 失败**（含初始化／清理）。新增测试覆盖 PNG 位深推断与原始字节往返、明确拒绝不支持的特性、PatchMatch 确定性／覆盖／原生精度、上游固定种子阴影参考场景及原容差、实际对话框分区重置和文件夹枚举。原有渲染、GPU 分流、选区／撤销和更新回归通过；便携包仅使用随包及系统运行库，测试专用文件不进入发布包；八套语言目录的 623 个键一致。

### 边界

完整合并源代码不代表所有 macOS 功能都自动移植。本补丁不新增 HDR／EXR、CMYK 软打样及导入／导出、渐进模糊、高斯模糊保持透明度、平滑圆角、新 macOS RAW 显影选项，或原生分辨率／Metal Camera Raw 预览。Windows 原生预览管线独立保留。16 位灰度蒙版属于 Windows 扩展，原版 macOS 当前仍只接受 8 位 PNG 蒙版。
