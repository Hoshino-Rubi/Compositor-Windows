# Compositor for Windows 0.5.5 — Upstream 1.7.4 Sync

Stable release for Windows 10/11 x64, built with native C++20 / Qt 6 Widgets.

- Merges all **227 upstream commits** through [`7b85bfd`](https://github.com/robbietilton/Compositor/commit/7b85bfd71b25278345a0777b678c343ce99cd62f), the Compositor 1.7.4 update-feed commit.
- Windows opens ordinary upstream `.comp` projects tagged through **format v23**, provided they only use supported layer features. Unsupported animated GIF and linked movie layers, shape inside strokes and unsupported adjustment layers are rejected rather than silently losing content. Existing Windows projects remain readable and the diagnostics are available in all eight interface languages.
- Camera Raw's existing luminance noise slider now uses upstream non-local means on the CPU in 8- and 16-bit workflows. This does not add a standalone Reduce Noise filter or port the Metal acceleration. Full-resolution processing can take longer.
- Saving is unchanged: native 16-bit masks keep their original precision; **Compatibility mode** writes standard 8-bit masks plus lossless Windows sidecars. Copy the entire `.comp` folder to retain the sidecars. Keep an original if resaving in macOS, which may drop them.

**Scope:** the upstream source merge does not port the new macOS timeline, video layers, standalone lighting and noise-reduction tools, or new macOS interactions to Windows. No new runtime dependency; the executable and updater remain unsigned.

## Downloads

- `Compositor-0.5.5-win-x64.zip`: portable application. Extract the complete archive or update through **Help → Check for Updates**.
- `Compositor-0.5.5-lens-dependency-sources.zip`: unchanged corresponding sources and build recipes for the bundled lens dependencies; not required to run the application.
- Both ZIP files include separate SHA-256 checksums.

## Compositor Windows 0.5.5 — 同步上游 1.7.4

Windows 10/11 x64 正式版，使用原生 C++20 / Qt 6 Widgets。

- 合并全部 **227 个上游提交**，同步至 Compositor 1.7.4 更新源提交 [`7b85bfd`](https://github.com/robbietilton/Compositor/commit/7b85bfd71b25278345a0777b678c343ce99cd62f)。
- Windows 可打开截至 **v23**、且仅使用已支持图层功能的普通上游 `.comp` 项目。GIF 动画、链接视频、形状内描边和不支持的调整层会被明确拒绝，避免静默丢失内容。已有 Windows 项目仍可打开，相关提示覆盖八种界面语言。
- Camera Raw 现有的亮度降噪滑杆改用上游非局部均值算法，在 8／16 位工作流中使用 CPU。未新增独立降噪滤镜，也未移植 Metal 加速；全分辨率处理可能更耗时。
- 保存行为不变：原生 16 位蒙版保留原精度；**兼容模式**仍写入标准 8 位蒙版和供 Windows 读取的无损 16 位副本。请复制完整 `.comp` 目录；若在 macOS 版重新保存，副本可能被移除，请保留原件。

**范围：**本次源码合并未把 macOS 新增的动画时间轴、视频图层、独立灯光及降噪工具和其他新交互移植到 Windows。无新增运行时依赖，主程序与更新助手仍未签名。

可通过“帮助 → 检查更新”升级，或完整解压 `Compositor-0.5.5-win-x64.zip`。镜头依赖源码包沿用上一版内容，运行无需下载。两个 ZIP 均提供独立的 SHA-256 校验文件。
