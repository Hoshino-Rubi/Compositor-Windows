# Compositor for Windows 0.5.3 — Workflow and Project Compatibility

**Stable release.** Native C++20 / Qt 6 Widgets, Windows 10/11 x64.

## What's new

- **Compatible project saves:** Save/Save As adds a Compatibility mode checkbox. Leave it unchecked to keep native 16-bit masks. Enable it to write upstream-readable 8-bit masks while retaining lossless 16-bit originals inside the project for reopening in Windows. Image layers are not reduced to 8-bit.
- **Paste and drop:** paste an image or copied image files on the welcome page to create documents. Drop images or projects on the tab bar's empty area to open new tabs. Drop layers there to create a canvas fitted to their transformed bounds, retaining relative placement and independent masks.
- **Editing controls:** middle-drag the layer list without changing selection. Drag numeric labels to adjust their values; Shift makes finer changes, Ctrl makes coarser changes, and Escape cancels. Drag with the Zoom tool to zoom, with an immediately updated plus/minus cursor.
- **Keep editing during saves:** saving writes a captured snapshot in the background. Later edits stay unsaved, tab switching remains available, and save completion updates the original document rather than whichever tab is active.
- **CMYK profile management:** choose installed Windows or imported profiles from View → CMYK Profiles. Imported profiles are retained locally; inactive imported copies can be removed without changing system profiles.
- **Install and Restart:** after a verified update download, choose to install and relaunch or keep the ZIP for later. Unsaved work is checked first. A native helper waits for the editor to exit, replaces application package files, rolls back detected failures and reopens saved projects.
- New controls and messages are translated in all eight interface languages.

## Compatibility and update notes

- **New documents default to compatibility mode off.** Ordinary Save retains that project's last successful mode; Save As lets you change it.
- Native saves containing 16-bit masks now explicitly use **Windows project format v15**. Older Windows builds and upstream 1.5.3 reject v15. Other saves use the minimum v11–v14 they need; Compatibility mode stays within upstream v11–v14.
- Copy the **entire .comp folder**, including its windows subdirectory, to retain exact 16-bit mask samples. Windows validates the precision copy and restores it only if the standard mask is unchanged. A mask edited externally takes precedence.
- An upstream re-save may discard Windows-only precision metadata/files. Exact 16-bit samples cannot be guaranteed after that re-save; keep the Windows original. Compatibility mode resolves mask-depth compatibility, not all cross-platform rendering differences.
- The updater requires the portable installation and its parent directory to be writable. It does not request administrator rights, remove unrelated files, or promise power-loss atomicity. Close other instances first. Recovery backups and a result log remain in a sibling .compositor-update-* directory. A successful process launch is not a guarantee against a later application crash.
- **Upgrading from 0.5.2 or earlier still requires manual extraction once**, because those versions do not contain the new installer helper. Keep CompositorUpdater.exe with the rest of the new package for subsequent updates.
- The application and updater remain unsigned. Existing RAW/Lensfun, object-selection, HDR/GPU and rendering limitations are unchanged.

## Verification

Targeted native and independently extracted portable validation covers core editing, upstream feature integration and the new interaction suite. Cases include 16-bit mask round trips, compatibility selection/cancel, externally changed masks, high-depth clipboard import, transformed layer drops, numeric scrubbing, middle scrolling, zoom cursor reversal, concurrent snapshot saves across tabs, CMYK profile storage, ZIP validation, detached installer wait/restart, rollback and preservation of unrelated files.

No macOS runtime or manual Explorer-dialog verification is claimed; upstream mask compatibility is checked against its current source requirements. The update flow is tested in isolated temporary portable directories, not by replacing a user's running installation.

## Download

Extract Compositor-0.5.3-win-x64.zip into a new folder and run Compositor.exe. Keep all executables, DLLs, plugins, translations, models and licenses together. A SHA-256 checksum is included.

### 兼容性与更新注意

- 新文档默认不勾选兼容模式。普通保存沿用本项目上次成功保存的模式，另存为可更改。
- 含原生 16 位蒙版的非兼容保存使用 **Windows v15**；旧 Windows 版和上游 1.5.3 会拒绝。其他项目按最低所需版本保存，兼容模式保持上游 v11–v14。
- 必须复制整个 .comp 文件夹（含 windows 子目录）才能保留精确的 16 位蒙版样本。Windows 校验附加数据，并仅在标准蒙版未被修改时恢复；若外部修改了标准蒙版，以外部修改为准。
- 上游重新保存可能丢弃 Windows 附加数据，因此不能保证上游重存后的精确 16 位恢复，应保留 Windows 原件。兼容模式解决蒙版位深兼容，不代表跨平台渲染完全相同。
- 更新要求便携目录和父目录可写，不请求管理员权限，不删除无关文件，也不保证断电原子性。先关闭其他实例。备份及结果日志保留在相邻的 .compositor-update-* 目录。进程成功启动不等于保证之后不会崩溃。
- **从 0.5.2 或更早版本升级，仍需手动解压这一次**，因为旧版不含新更新助手。后续更新需保留完整软件包，包括 CompositorUpdater.exe。
- 主程序及更新助手仍未签名；RAW／Lensfun、对象选择、HDR／GPU 和渲染边界保持不变。
