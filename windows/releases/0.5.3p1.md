# Compositor for Windows 0.5.3p1 — Automatic RAW Lens Correction

**Stable patch release.** Native C++20 / Qt 6 Widgets, Windows 10/11 x64.

## What's new

- **Automatic RAW lens correction:** supported embedded DNG corrections take priority; otherwise Compositor selects a matching profile from its bundled offline Lensfun database. Available correction is enabled when the RAW development dialog opens.
- **Distortion and vignetting:** matching uses the camera and lens identity, compatible mount and sensor crop, with calibration interpolation at the recorded focal length and aperture. Missing or ambiguous matches are explained instead of silently choosing a similar lens. Vignetting is not enabled without aperture metadata; unknown focus distance uses the library's infinity approximation.
- **Clear controls:** see the selected profile and available correction types, disable correction, load a single-lens XML manually, or return to the automatic profile. Reset restores the automatic selection.
- **16-bit processing:** correction works on linear 16-bit pixels before display encoding. Sensor orientation and supported DNG default crop are respected. Cached reduced previews avoid repeating full-image correction for ordinary exposure changes; final import processes the full-resolution source in the background.
- **Offline database:** includes a pinned Lensfun database snapshot with 1,057 camera and 1,571 lens entries. Individual entries have different calibration coverage. Imports do not download profiles or upload photographs.
- **Patch-version updates:** the version checker now understands stable `pN` patches, as well as existing stable and alpha versions. New messages are available in all eight interface languages.

## Upgrade

**Download and extract this patch manually if you are running 0.5.3 or earlier.** Those versions cannot recognize the new stable `p1` suffix. Keep all files in the portable package together; subsequent recognized updates can use Install and Restart.

## Compatibility

Embedded support covers DNG OpcodeList3 **WarpRectilinear, WarpFisheye and FixVignetteRadial**, using a common warp for all channels. Unsupported required operations and channel-dependent warps are not approximated; optional unimplemented operations are identified as partial support. A supported embedded correction is not stacked with Lensfun correction.

This does not implement every manufacturer's proprietary embedded lens profiles, DNG GainMap/ACM models, or Apple's RAW processing engine. Unknown equipment can still require a manually supplied profile. Lensfun supplies distortion/vignetting calibration, not a guarantee that every listed lens supports both at every shooting setting. Existing object-selection and cross-platform rendering differences remain.

Project format, compatibility-mode mask behavior and GPU routing are unchanged. The application and updater remain unsigned.

## Verification

Native validation: **205 passed, 2 optional skips, zero failures**. The skips are the opt-in GPU benchmark and an unavailable external HEIC-alpha fixture.

Targeted validation covers RAW metadata extraction, embedded opcode decoding, database matching and ambiguity, calibration application, 16-bit precision, orientation/default crop, manual override, RAW dialog toggle/reset/import, and stable patch ordering. The existing core, upstream integration and interaction suites are also checked in the native build and an independently extracted portable package. No macOS runtime or all-camera hardware certification is claimed.

## Downloads and licenses

- `Compositor-0.5.3p1-win-x64.zip`: complete portable application, with SHA-256 checksum.
- `Compositor-0.5.3p1-lens-dependency-sources.zip`: corresponding sources and build recipes for the new native lens-correction dependencies; not needed to run the app. A SHA-256 checksum is included.

Lensfun and its runtime dependencies are dynamically linked, with license notices included. The modified database snapshot is distributed under CC BY-SA 3.0 with source attribution.

## 0.5.3p1 — RAW 自动镜头校正

**正式补丁版**，原生 C++20 / Qt 6 Widgets，支持 Windows 10/11 x64。

- **自动校正：**优先使用支持的 DNG 内嵌校正，否则从随软件附带的离线 Lensfun 数据库自动匹配；有可用校正时，在 RAW 显影窗口默认开启。

**0.5.3 及更早版本无法识别新的正式版 `p1` 后缀，本次需要手动下载并解压。** 保留完整便携包文件，之后可继续使用“安装并重启”更新受支持的新版本。

### 范围

DNG 内嵌校正支持 OpcodeList3 的 **WarpRectilinear、WarpFisheye、FixVignetteRadial**，几何变形使用所有通道共用的系数。不把不支持的必需操作或逐通道变形伪装为已支持；跳过可选未知操作时会显示“仅支持的处理项”。可用内嵌校正不会与 Lensfun 重复叠加。

不代表支持所有厂商私有内嵌配置、DNG GainMap／ACM 模型或 Apple RAW 引擎。未知设备可能仍需手动提供配置；数据库中的镜头并非在所有拍摄参数下都具备畸变和暗角标定。此前对象选择及跨平台渲染差异仍然存在。

项目格式、兼容模式蒙版行为和 GPU 分流策略不变。主程序及更新助手仍未签名。

原生验证 **205 项通过、2 项可选测试跳过、0 失败**；跳过的是未启用的 GPU 性能报告和缺少外部样本的 HEIC-alpha 测试。

定向验证覆盖 RAW 元数据、内嵌数据解析、数据库匹配／歧义、校正应用、16 位精度、拍摄方向／默认裁切、手动覆盖、显影窗口的开关／重置／导入和补丁版本排序，并在原生构建及独立解压便携包检查现有核心、上游整合和交互套件。未声称已在 macOS 运行或验证所有相机硬件。
