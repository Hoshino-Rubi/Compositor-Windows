# Compositor for Windows 0.5.0 — Stable Performance Release

**Stable release. Replaces 0.4.0 as Latest.** Windows 10/11 x64, native C++20 / Qt 6 Widgets.

## What's included

This release consolidates the validated improvements from 0.4.1a1–a9 without re-enabling slower experimental editing paths.

- **Responsive previews:** reuse source textures and transfer buffers, update dirty rectangles, and skip unchanged compositing/readback. The native canvas displays supported GPU composites directly; CPU reference preview remains available for accuracy checks and unsupported hardware.
- **Sharper Liquify and Smudge:** accumulated displacement samples the original image instead of repeatedly blurring it; carried color produces a fading smudge trail. Supported larger gestures retain GPU resources across pointer events, upload the original once and read back the changed region once per segment. Native 8/16-bit pixels, selections, masks, cancel and undo are retained. A failed GPU gesture replays from its original source on CPU.
- **Selective acceleration:** retain GPU adjustments, blend modes, effects and eligible Camera Raw/standalone filters. Ordinary painting, erasing, cloning, blur brush, healing, perspective, active sequential luminance denoising and Atkinson/Floyd–Steinberg remain on CPU. Standalone Motion Blur at or below 256 KiPixels also uses CPU after fresh measurements found unreliable GPU gains there; resident adjustment layers are unchanged. The retired GPU editing implementations are now test-only dependencies, not part of the application link graph. Old experimental preferences cannot re-enable them.
- **Reference workflows:** reuse unchanged full-image reference previews while panning and tile eligible local, pixel-aligned exports. Unsafe transforms, global adjustments and nonuniform resizing retain full reference rendering. CPU export is the default; GPU export is an explicit alternative, not a silent pixel change.
- **Object selection and updates:** aspect-preserving local inference, missed-click crop retry and transparent-pixel exclusion; opt-in update checks and size/SHA-256-verified downloads. Installation is manual. Stable builds ignore prereleases; existing alpha builds can upgrade to 0.5.0.
- **Release consistency:** a single version source drives the displayed version, Windows file/product metadata and archive name. Packaging rejects a mismatched executable. Eight interface languages and existing 8/16-bit project formats are unchanged.

## Validation and performance

Native Release and independently extracted portable builds each: **207 passed, one optional external HEIC-alpha fixture skipped, zero failed**, including initialization/cleanup across nine Qt Test suites. Strict hardware runs cover rendering, editing, selections/undo, resources/fallback, safe export, native display, stable-channel upgrades and pixel parity. Portable tests passed with only bundled/system runtime paths; test-only libraries were added to the validation extraction, not the release archive. Windows product/file/CLI versions are 0.5.0 and the executable prerelease flag is clear. A stale prior-version executable is rejected by packaging. Eight catalogs retain matching 621-key sets.

Warm medians of three local runs: 512×512 image, 160px radius, six segments of seven dabs. These compare the same stateful CPU/GPU algorithm and include per-segment processing, synchronization, readback and CPU output copies. Initial shader/source/field setup, the first dab and UI presentation are excluded. GPU dispatch, zero subsequent source uploads and six readbacks are asserted; final pixels are compared with the CPU reference.

|---|---:|---:|---:|
| Liquify | 8-bit | 8.602 ms | 304.858 ms |
| Smudge | 8-bit | 8.441 ms | 90.358 ms |
| Liquify | 16-bit | 10.937 ms | 316.932 ms |

These measurements justify retaining this route in the tested workload, not a universal speedup on every GPU or image.

## Compatibility and limits

- GPU/Qt/Metal geometry, effect edges and fonts are not universally pixel-identical. Use reference CPU preview and the default CPU export where reference rendering matters. Destructive edits save their actual result.
- Stateful GPU retouch currently retains full-layer resources up to 8MP, within the shared memory budget. Larger/unsupported cases use CPU. Changed editing segments still synchronize a readback and copy a CPU result; this is not a fully GPU-resident editor.
- Full-image filters and unsafe tiled cases may still need large temporary allocations. Object selection uses the bundled local model, not Apple Vision.
- **The executable remains unsigned:** no release certificate was provided. Download verification does not replace publisher signing. Updates do not automatically replace the app or relaunch it; GitHub outages/rate limits can prevent checks.
- Automated GPU/hidden-window tests do not certify every GPU, driver, display or DPI configuration. CMYK/32-bit PSD, floating-point HDR and PSD export remain unsupported.

## Download

Extract `Compositor-0.5.0-win-x64.zip` into a new folder and run `Compositor.exe`. Keep the bundled DLLs, plugins, models and licenses together. No Qt SDK, Python, Node.js or browser runtime is required. The accompanying `.sha256` file verifies the archive. Keep the previous installation until you have checked your projects in the new version.

## 0.5.0 — 性能整合正式版

**正式发布，取代 0.4.0 成为 Latest。** Windows 10／11 x64，原生 C++20／Qt 6 Widgets。

### 本次整合

整合 0.4.1a1–a9 已验证的改进，不重新启用较慢的实验 GPU 编辑路径。

- **预览：**复用源纹理／传输缓冲、更新脏区域，未变化时跳过合成与回读；原生画布直接显示受支持的 GPU 合成纹理。保留 CPU 参考预览与硬件不支持时的回退。
- **液化／涂抹：**液化累积位移并从原图采样，减少反复重采样的模糊；涂抹携带混合后的颜色。合适的大笔刷在移动段之间保留 GPU 资源，源图只上传一次，每段仅回读变化区域。保留 8／16 位、选区、蒙版、取消、撤销；GPU 中途失败从原图进行 CPU 重放。
- **选择性加速：**保留 GPU 调整层、混合、效果及适用的 Camera Raw／独立滤镜。普通画笔、橡皮、克隆、模糊、修复、透视、顺序亮度降噪和 Atkinson／Floyd–Steinberg 使用 CPU。复测发现小图独立动态模糊的 GPU 收益不稳定，因此不超过 256 KiPixels 时也走 CPU，已驻留 GPU 的调整层保持不变。退役 GPU 编辑模块仅供测试，不再进入应用链接依赖，旧实验设置不能重新启用。
- **参考流程：**平移时复用未变化的整图参考预览；适合局部处理且像素对齐的大图分块导出。不安全的变换、全局调整和非等比缩放保持整图参考路径。CPU 导出仍为默认，GPU 需明确选择。
- **对象选择与更新：**推理保持比例、未命中点击尝试局部裁切、排除透明像素。更新检查自愿开启，下载验证大小和 SHA-256，仍手动安装。稳定版忽略预发布；已有 alpha 可升级到 0.5.0。
- **发布一致性：**单一版本源统一程序版本、Windows 文件属性和便携包名称，打包时拒绝版本不符的程序。保留八种语言和原有 8／16 位项目格式。

原生 Release 与独立解压的便携包各自九套测试共 **207 项通过、1 项可选外部 HEIC-alpha 样本测试跳过、0 失败**（含初始化／清理）。便携包已在只使用随包和系统运行库的环境通过相同测试；测试专用库仅放入验证目录，不进入发布包。覆盖实际 GPU 调度、像素对照、选区／撤销、回退、缓存和资源释放、导出、原生显示、稳定频道升级。程序及 Windows 文件版本均为 0.5.0，预发布标记关闭；打包会拒绝旧版本程序。八套翻译保留一致的 621 个键。
