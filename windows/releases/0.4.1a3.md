## Pre-release — GPU pipeline, batch 3

**0.4.1a3 is an experimental pre-release. Stable Latest remains 0.4.0.** Keep project backups. Future GPU batches remain pre-releases unless a stable release is explicitly approved.

### Changes

- Compute **Normal-blend Gaussian Blur adjustment layers on Direct3D 11**, for both 8-bit and 16-bit previews. Multiple blur adjustment layers may be interleaved with ordinary raster layers.
- Use six horizontal/vertical integer box passes with a shared-memory prefix scan, preserving the CPU Gaussian approximation's edge clamping and truncation after each pass. This is the same approximation used by the Windows CPU renderer, not a different blur profile.
- Mix the adjusted result through layer masks, linked/unlinked mask placement, clipping sources, ancestor masks and combined layer/folder opacity. Coverage remains CPU-prepared and cached. Unsupported adjustment types, non-Normal blur blend modes or live layer effects fall back to CPU preview rendering.
- Reuse source, coverage and blur scratch textures while changing the blur radius; identical preview requests skip dispatch/readback. Both scratch textures count toward the existing retained-cache budget. Hardware/resource/budget failures use the reference CPU path.
- Use the accelerated renderer in adjustment-dialog previews, with a stable temporary layer identity across control changes. Cancel leaves document pixels, undo history and dirty state unchanged. High-zoom region previews retain blur halos to avoid tile seams.

### Verification

The native build and extracted portable package each passed **104 tests**, with **0 failures** and **1 optional HEIC-alpha fixture test skipped**. Hardware GPU tests ran with `COMPOSITOR_REQUIRE_GPU=1`.

New checks cover both depths; transparent and fine 16-bit samples; single-pixel, narrow, odd-sized and cross-block images; blur radii from 0.1 to 250; edge clamping; multiple blur layers; masks, clipping and folder opacity; scaled and high-zoom region previews; radius/pixel edits and undo/redo; cache reuse and budget fallback; unsupported CPU fallback; and actual adjustment-dialog preview/cancel behavior. Pure-kernel and region comparisons are pixel-exact in these tests. Complex masked stacks retain a tolerance of two 8-bit steps or four 16-bit steps against CPU composition. Existing 24-blend and editing/import/export regressions still pass.

### Measured workload

The extracted portable package rendered a **1024×1024 document with one raster layer and one Gaussian Blur adjustment**, changing radius **six times (5, 9, 13, 17, 21, 25)**. The GPU source/coverage cache and shaders were already warm. Every GPU frame matched the CPU reference exactly.

| Six previews | CPU reference | Warm GPU preview |
| --- | ---: | ---: |
| 8-bit total time | 543.659 ms | 13.482 ms |
| 16-bit total time | 777.579 ms | 68.938 ms |

Each GPU run performed 36 blur passes and six readbacks, with **zero new texture allocations or source uploads**. Readback payload was 24 MiB for 8-bit and 48 MiB for 16-bit. These are local results from one controlled workload; first-use shader compilation/upload, other documents and other hardware can behave differently. Timings vary, and this is **not a universal speedup claim or a direct benchmark against 0.4.1a2**.

### Download

Windows 10/11 x64: extract **Compositor-0.4.1a3-win-x64.zip** and run **Compositor.exe**. Keep DLLs, plugins, translations, models and licenses together. Unsigned portable build.

- ZIP: **26,268,034 bytes**.
- SHA-256: `1c562bd08e332e4416ec3860d4b47dae4ca1b31674fa42194bae1678a8770c3d`; matching `.sha256` attached.

### Scope and remaining work

This batch migrates **Gaussian Blur preview computation**, not destructive filter application or export. A changed preview with a visible blur fully recomputes the requested viewport/region because of spatial dependencies; raster-only previews retain a2's dirty rectangles. CPU source/mask preparation, brush/eraser/clone/healing kernels, transforms, other filters/Camera Raw, effects and export remain. Readback still synchronizes with the CPU: **not zero-copy presentation or a complete GPU editor**.

No new runtime dependency, browser runtime, UI language or project-format change. The existing eight languages and 8/16-bit project/export precision are preserved. CMYK/32-bit PSD and floating-point HDR remain unsupported. `COMPOSITOR_DISABLE_GPU=1` forces CPU previews; `COMPOSITOR_GPU_CACHE_MB` lowers the retained-cache budget and `COMPOSITOR_GPU_FULL_FRAME=1` remains available for diagnostics.

## 预发布 — GPU 管线第三批

**0.4.1a3 是实验性预发布，稳定版 Latest 保持 0.4.0。** 测试前请备份项目。未得到稳定版发布许可前，后续 GPU 批次也只发布为 Pre-release。

### 更新内容

- 使用 **Direct3D 11 计算 Normal（正常）混合模式的高斯模糊调整层**，支持 8 位和 16 位预览，以及多个模糊调整层与普通图层交错。
- 通过共享内存前缀和实现六次横／纵整数盒式模糊，保留 CPU 高斯近似算法的边缘夹取及逐次截断。这与 Windows CPU 渲染器采用相同近似算法，不更换模糊效果模型。
- 调整结果支持图层蒙版、关联／独立蒙版位置、剪贴来源、祖先组蒙版，以及图层／组综合不透明度。覆盖率仍由 CPU 准备并缓存。其他调整类型、非 Normal 模糊混合模式或实时图层效果回退 CPU 预览。
- 修改半径时复用源图、覆盖和模糊临时纹理；相同预览不计算／回读。两个临时纹理计入原有缓存预算，硬件／资源／预算不足时使用 CPU 参考路径。
- 调整对话框预览接入加速渲染，控件变化之间使用稳定临时图层 ID；取消不改变文档像素、撤销记录或修改状态。高倍率区域预览保留模糊边界扩展，避免分块接缝。

### 验证

原生构建和解压便携包均为 **104 项通过、0 失败、1 项可选 HEIC 透明度样本测试跳过**。通过 `COMPOSITOR_REQUIRE_GPU=1` 要求并实际执行硬件 GPU 测试。

新增覆盖两种位深、透明及细粒度 16 位样本、单像素／窄图／非整齐尺寸／跨计算块、0.1–250 半径、边缘夹取、多个模糊层、蒙版／剪贴／组不透明度、缩放及高倍率区域预览、半径／像素修改与撤销重做、缓存复用和预算回退、不支持情况的 CPU 回退，以及实际调整弹窗预览和取消行为。基础内核及区域对比在这些测试中逐像素一致；复杂蒙版堆栈与 CPU 合成的容差为两个 8 位步长或四个 16 位步长。原有 24 种混合模式和编辑／导入／导出回归继续通过。

### 实测场景

解压便携包使用 **1024×1024、一个普通图层加一个高斯模糊调整层**，连续六次设置半径 **5、9、13、17、21、25**。GPU 源图／覆盖缓存和着色器已预热，每一帧 GPU 结果与 CPU 参考结果完全相同。

| 六次预览 | CPU 参考路径 | 热缓存 GPU 预览 |
| --- | ---: | ---: |
| 8 位总耗时 | 543.659 ms | 13.482 ms |
| 16 位总耗时 | 777.579 ms | 68.938 ms |

每组 GPU 测试执行 36 次模糊计算和六次回读，**没有新建纹理或重新上传源图**。8 位回读量 24 MiB，16 位 48 MiB。这是本机单个受控场景；首次着色器编译／上传、其他文档和硬件可能不同，耗时也会波动。**不承诺普遍提速，也不是与 0.4.1a2 的直接性能对比。**

### 范围和剩余工作

本批迁移的是**高斯模糊预览计算**，不是直接修改像素的滤镜应用或导出。含可见模糊的变化预览因空间依赖而完整重算请求的视口／区域；仅含普通图层的预览继续使用 a2 局部矩形。源图／蒙版准备、画笔／橡皮／克隆／修复内核、变换、其他滤镜／Camera Raw、图层效果和导出仍使用 CPU。回读仍需与 CPU 同步，**不是零拷贝显示，也不是完整 GPU 编辑器**。

不增加运行时依赖、浏览器运行时或界面语言，不修改项目格式。保留原有八种语言及 8／16 位项目／导出精度；仍不支持 CMYK／32 位 PSD 和浮点 HDR。`COMPOSITOR_DISABLE_GPU=1` 强制 CPU 预览，`COMPOSITOR_GPU_CACHE_MB` 可下调保留缓存预算，`COMPOSITOR_GPU_FULL_FRAME=1` 继续作为诊断开关。
