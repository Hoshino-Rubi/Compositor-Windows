## Pre-release — GPU pipeline, batch 2

**0.4.1a2 is an experimental pre-release. Stable Latest remains 0.4.0.** Keep project backups. Subsequent GPU batches will also be pre-releases unless a stable release is explicitly approved.

### Changes

- Recompose only the bounding rectangle of changed prepared layer pixels. Every visible layer is blended inside that rectangle from a transparent background; pixels outside it retain the previous result. Visible layer order, visibility and blend-mode changes conservatively recompose the complete viewport.
- Pack GPU output into native **8-bit BGRA / 16-bit RGBA integer samples**, then copy only the dirty rectangle to staging and the QImage. This removes the CPU's full-image floating-point conversion loop and reduces the logical readback payload. Unsupported hardware/resources fall back to the reference CPU renderer.
- Derive dirty bounds from actual prepared surfaces, including masks, clipping sources, linked/unlinked masks, transforms, folder opacity and undo/redo. Old and new positions are both covered; previously returned images stay immutable. Changes with identical prepared pixels avoid compute dispatch and readback.
- Add `COMPOSITOR_GPU_FULL_FRAME=1` for diagnostics: force full viewport recomposition/readback while keeping source texture caching and packed output. The existing `COMPOSITOR_GPU_CACHE_MB` budget and `COMPOSITOR_DISABLE_GPU=1` CPU fallback controls remain available.
- Preserve native C++20/Qt 6, all eight interface languages, project formats and export precision. No new runtime dependency or browser runtime.

### Verification and measured workload

Native build and extracted portable package: **98 tests passed, 0 failed, 1 optional HEIC-alpha fixture test skipped**. Hardware GPU tests actually ran. New checks cover native channel order, transparency and fine 16-bit samples, odd dimensions and edge pixels, partial/full recomposite equality across all 24 blend modes at both depths, stack changes, mask/transform/history invalidation, immutable old frames and no-pixel-change updates.

The extracted portable benchmark used a **1024×1024, 8-bit, six-layer document** with **12 edits to a 32×32 region**. Both runs kept a warm cache and used the new packed output; only full versus partial recomposition/readback differed. Every output frame matched exactly.

| Measurement, 12 frames | Forced full viewport | Dirty rectangle |
| --- | ---: | ---: |
| Total time | 54.323 ms | 37.430 ms |
| Logical readback payload | 48 MiB | 48 KiB |
| Layer-pixels composited | 75,497,472 | 73,728 |
| Source uploads | 48 KiB | 48 KiB |
| New texture allocations | 0 | 0 |
| CPU-prepared surfaces / readbacks | 12 / 12 | 12 / 12 |

These are local results for one controlled workload, **not a universal speedup claim or a direct benchmark against 0.4.1a1**. Byte/pixel counters describe requested payload and valid pixels, excluding driver row-pitch, dispatch padding and transfer overhead.

### Remaining CPU work and limitations

Changed layer surfaces and their differences are still prepared on the CPU. Brush/eraser/clone/healing kernels, transforms/masks, filters/Camera Raw, live adjustments/effects and export remain CPU-backed. Changed previews still synchronize GPU readback; an older frame held by the UI can require a full CPU image copy. Distant edits share one bounding rectangle rather than sparse tiles. This is **not zero-copy presentation or a complete GPU editor**. Existing CMYK/32-bit PSD and floating-point HDR limitations remain; GPU previews may differ slightly in rounding from CPU reference output. Export keeps the CPU reference path.

## 预发布 — GPU 管线第二批

**0.4.1a2 是实验性预发布，稳定版 Latest 保持 0.4.0。** 测试前请备份项目。未得到稳定版发布许可前，后续 GPU 批次也只发布为 Pre-release。

### 更新内容

- 仅对准备后图层像素的变化包围矩形进行重合成。矩形内从透明背景重新混合所有可见图层，区域外保留已有结果；可见层序、显隐或混合模式变化时，保守地重算完整视口。
- GPU 直接将结果打包成原生 **8 位 BGRA／16 位 RGBA 整数样本**，仅将变化矩形复制到回读资源和 QImage。移除 CPU 对整幅浮点结果的逐像素转换，减少逻辑回读量；硬件／资源不支持时回退 CPU 参考渲染。
- 依据实际表面差异确定区域，覆盖蒙版、剪贴来源、关联／独立蒙版、变换、组不透明度及撤销／重做，也覆盖移动前后的位置。旧预览保持不变；准备后像素完全相同时不触发 GPU 计算或回读。
- 新增诊断开关 `COMPOSITOR_GPU_FULL_FRAME=1`：保留源纹理缓存和紧凑输出，但强制完整视口重合成／回读。原有 `COMPOSITOR_GPU_CACHE_MB` 预算及 `COMPOSITOR_DISABLE_GPU=1` CPU 回退开关继续可用。
- 保持原生 C++20／Qt 6、八种界面语言、项目格式及导出精度，不增加运行时依赖或浏览器运行时。
