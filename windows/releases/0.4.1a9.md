# Compositor for Windows 0.4.1a9 — Sharper Retouching and Reference Workflows

**Pre-release only. Stable Latest remains 0.4.0.**

## Changes

- **Sharper Liquify:** a gesture accumulates displacement and samples the untouched source instead of repeatedly resampling already-warped pixels. Smudge carries the color it just painted, producing one fading trail rather than repeated stamps. Both support native 8/16-bit pixels, selections, masks, cancel and undo.
- Larger supported brush gestures retain their original image, displacement field or carried color on Direct3D 11 across pointer events. Subsequent segments do not reupload the source image. Resources count toward the shared GPU budget; small brushes, images above the current 8MP resident limit, unavailable hardware and resource failures use the same stateful CPU algorithm. A failed GPU gesture is replayed from its original source rather than partially applied.
- **Retired slower experimental editing routes:** ordinary painting, erasing, cloning, blur brush, healing and perspective consistently use reference CPU processing. Old experimental settings cannot reenable them. Proven GPU adjustments/filters, native display and the separate export renderer remain independent.
- Large pixel-aligned, local compositions can use tiled CPU export, reducing full-canvas intermediate surfaces. Fractional/rotated/resampled placements, global-coordinate adjustments and nonuniform output resizing retain full reference rendering. A new regression caught a transformed Qt clipping discrepancy and prevents that unsafe tiling route.
- CPU detailed previews reuse the global-adjustment composite while panning an unchanged document. Document identity, revision, canvas size and rendering mode invalidate reuse. Preferences can explicitly select **reference CPU previews**, avoiding GPU-versus-reference rendering differences when checking an image.
- Object selection preserves aspect ratio during model inference, retries a missed click on a local crop, retains only its connected foreground and excludes fully transparent source pixels. The bundled local model is unchanged; this is not equivalent to macOS Vision or guaranteed arbitrary-object segmentation.
- **Check for Updates** in Help, with optional startup checks in Preferences. Stable installations do not receive alpha offers; alpha installations compare alpha/patch versions numerically. Downloads require the expected repository URL, archive name, size and SHA-256 digest, and are saved atomically only after verification. Installation remains manual into a separate folder; open documents and the existing installation are never silently replaced.
- All new controls/messages are translated in eight languages. The portable package now includes Qt Network and its Windows TLS backend; no separate SDK or scripting runtime is required. Project format is unchanged.

## Validation and performance

Native Release: **205 passes, 1 optional external HEIC-alpha fixture skipped, zero failures** across nine Qt Test suites, including initialization/cleanup. The 16-test completion suite checks CPU/GPU gesture parity (at most one native channel level in its fixtures), large-coordinate 16-bit precision, edge coverage, device/budget fallback and resource release, detail retention, one fading smudge trail, preview cache invalidation, reference-preview routing, safe CPU-export fallback, transparency, retired settings and update metadata/TLS support. Portable parity is a release gate.

Warm medians of three runs, 512×512 image, 160px radius, **six segments of seven dabs**. Initial shader/source/field setup and the first dab are excluded; the timed segments include their computation, synchronization, CPU readback/copy and any newly touched CPU field blocks. No UI presentation is timed. This compares the same new stateful algorithm, not old/new output from different algorithms.

| Tool | Depth | GPU | CPU reference |
|---|---:|---:|---:|
| Liquify | 8-bit | 7.955 ms | 295.590 ms |
| Smudge | 8-bit | 8.909 ms | 88.565 ms |
| Liquify | 16-bit | 16.865 ms | 308.603 ms |
| Smudge | 16-bit | 16.772 ms | 95.192 ms |

These local samples justify retaining this GPU route; they do not promise a speedup on every image or GPU. Ordinary editing routes retired above are not enabled by these results.

## Remaining limits

- **Not a claim that all remaining work is complete.** GPU/Qt/Metal edges and fonts are not universally pixel-identical; reference preview is an explicit alternative, not a rewritten Metal renderer.
- Global full-resolution filters can still require large intermediates. Stateful GPU retouch currently retains full-layer resources up to 8MP; larger layers use sparse CPU displacement blocks. Per-segment output still synchronizes one readback and copies the CPU result.
- GitHub API rate limits or service failures can prevent update checks. A live unauthenticated check in this environment reached GitHub over TLS but received HTTP 403 (rate limit); deterministic metadata validation and packaged TLS availability are tested separately. No token is required or embedded.
- The application remains **unsigned**: no release-signing certificate was supplied. A PowerShell 7 signing/verification script accepts an explicitly selected code-signing certificate; no self-signed certificate or trust-store modification is substituted. Automatic replacement/relaunch is not implemented.
- Automated hardware and hidden-window tests do not certify interactive behavior across multiple GPUs, drivers, monitors and DPI configurations. No such manual certification is claimed.
- CMYK/32-bit PSD, floating-point HDR and PSD export remain outside this batch.

Extract `Compositor-0.4.1a9-win-x64.zip` into a new folder and run `Compositor.exe`, keeping all bundled files together. Windows 10/11 x64. SHA-256 is provided alongside the archive.

## 0.4.1a9 — 更清晰的修饰与参考渲染流程

**仅预发布；稳定版 Latest 保持 0.4.0。**

- 液化保存整笔画累计位移，从未改动的原图取样，减少反复重采样造成的模糊。涂抹携带刚刚混合后的颜色，不再反复盖印旧样本。支持 8／16 位、选区、蒙版、取消和撤销。
- 合适的大笔刷在 Direct3D 11 保留笔画资源，后续鼠标移动段不再上传整张源图，资源计入共享预算。小笔刷、超过当前 8MP 常驻上限或资源不足时使用同算法 CPU 路径；GPU 失败从原图重放，不提交半成品。
- 普通画笔、橡皮、克隆、模糊笔刷、图像修复和透视固定使用 CPU，撤下无性能收益的实验入口，旧设置不能重新启用。已有 GPU 调整／滤镜、原生显示和独立导出选择不受影响。
- 大图中像素对齐、仅涉及局部操作的组合可使用 CPU 分块导出。旋转、小数位置、重采样、全局调整和非等比缩放保留整图参考渲染，避免测试中发现的 Qt 分块边缘差异。
- 平移未修改的文档时，CPU 细节预览复用全局调整合成。首选项新增 CPU 参考预览，方便检查与参考渲染器的差异。
- 对象选择保留推理图像比例，点击未命中时尝试局部裁切推理，仅选中关联前景并排除透明像素。模型未更换，不承诺与 macOS Vision 等效或识别任意对象。
- 帮助菜单新增检查更新，首选项可选启动检查。稳定版不推荐 alpha；alpha／补丁版本按数字比较。下载检查固定仓库地址、文件名、大小及 SHA-256，通过后原子保存。仍需手动解压安装，不自动覆盖安装目录或打开的文档。
- 新文案覆盖八种语言。便携包新增 Qt Network／Windows TLS 插件，不需要另装 SDK 或脚本运行时；项目格式不变。

### 验证与性能

原生 Release 九套测试：**205 项通过、1 项可选 HEIC-alpha 外部样本测试跳过、0 失败**（含初始化／清理）。以上英文验证记录与计时表同样适用；计时包含相应笔画段的处理和回读，不代表所有设备或整套界面的性能。

### 明确保留的边界

**并非所有欠项都已清零。** GPU／Qt／Metal 边缘与字体仍不保证逐像素一致；参考预览是可选的准确性路径。全局大图滤镜仍可能需要整图临时空间，超过 8MP 的状态化修饰使用 CPU；每段最终回读与 CPU 结果复制仍存在。

本环境的实际匿名更新请求通过 TLS 到达 GitHub，但遭遇公开 API 限流（HTTP 403）；元数据校验与便携包 TLS 可用性另行验证。程序不要求或内嵌账号令牌。

未提供正式发行签名证书，因此程序仍未签名；提供了显式指定证书的签名／验证脚本，不创建自签名证书、不修改信任库。自动覆盖安装／重启尚未实现。多显卡、多驱动、多显示器／DPI 的人工交互验证也未完成，不能用自动化测试冒充。CMYK／32 位 PSD、浮点 HDR、PSD 导出不属于本批。

完整解压到新文件夹后运行程序，保留全部附带文件；支持 Windows 10／11 x64，附 SHA-256 校验文件。
