Built and verified on Windows x64 with MSVC 2022 and Qt 6.8.3, October 11, 2026 (Asia/Taipei). The upstream baseline remains Compositor 1.4.9 (`b4bfdea87f9dc0cbc9eabfa63683eb1b9c2bca60`).

- ZIP: 25877972 bytes; extracted application: 56823616 bytes. Increase over v0.3.2: 100072 bytes compressed.

- The extracted executable matches the tested Release build and reports version 0.3.3.
- The portable application opened a native 16-bit PNG in all three UI languages with only Windows system directories in PATH. English, Simplified Chinese and Traditional Chinese captures, including 150%/200% scaling, were inspected.
- All 66 tests also ran beside the packaged DLLs/plugins/models using the native Windows platform plugin. File dialogs are automated with Qt's widget implementation; the shipped application keeps the default native file dialogs.

New coverage checks actual low-order pixel values, rather than only image-format tags: 16-bit PNG/TIFF decoding and PNG export; v12 project/mask round trips and unchanged v11 output for 8-bit documents; PSD/PSB raw/RLE/ZIP/prediction with global Lr16 records and masks; all blend modes and filter categories; Camera Raw controls; brush/retouch/liquify/selection precision; RAW development; cancellation/confirmation of depth reduction and undo. Zero-tolerance wand selection distinguishes adjacent 16-bit values that map to the same 8-bit color.

Synthetic fixtures are generated by `windows/tests/generate_fixtures.py`. Additional PSD/PSB smoke coverage used `16bit5x5.psd`, `16bit5x5.psb` and `colormodes/4x4_16bit_rgb.psd` from the psd-tools repository, stored only under ignored `.tools/psd16-reference`; set COMPOSITOR_PSD16_FIXTURES to use them. The existing HEIC test used the pinned libheif `with-alpha-512x512.heic` fixture. These tests do not establish compatibility with every Photoshop document or camera.

The checked-in 16-bit C++ implementations regenerate byte-for-byte from their scripts. CMake validates hashes of the source algorithms. Python is not an application dependency or a normal build requirement. Developer scripts, test runners and source fixtures are excluded from the release ZIP.

16-bit integer sRGB is supported; CMYK and floating-point/32-bit editing are not. JPEG/PDF outputs are 8-bit derivatives. Version 12 projects are deliberately rejected by older Windows/macOS builds; convert a copy to 8-bit to save a v11 project. macOS tests were not run locally.
