# Compositor Windows 原生版

C++20 / Qt 6 Widgets，版本 **0.5.3（正式版）**。保留原版 Swift / AppKit / Metal 工程；Windows 应用没有浏览器运行时。

## 运行

从 [GitHub Releases](https://github.com/Hoshino-Rubi/Compositor-Windows/releases/tag/windows-v0.5.3) 下载正式版便携包。

解压 `Compositor-0.5.3-win-x64.zip` 后运行 `Compositor.exe`。保留 DLL、插件、translations、models 和 licenses 文件夹。Windows 10 / 11 x64，无需另装 Qt、Python 或 Node.js。
在“首选项”窗口即时切换 English、简体中文、繁體中文、日本語、한국어、Deutsch、Français、Español，或选择“跟随系统”。语言选择会保存。

## 0.5.3 — 工作流与项目兼容保存

- 保存／另存为的文件选择对话框新增 **兼容模式**，新文档默认不勾选。未勾选时保留原生 16 位蒙版；勾选时将标准蒙版写为上游支持的 8 位，同时在项目内部保存无损 16 位副本。Windows 重新打开时自动恢复原精度；若外部编辑器修改了标准蒙版，以外部修改为准，不覆盖成旧内容。普通保存沿用本项目上次成功保存的模式，另存为可切换。
- 欢迎页可直接粘贴图片或复制的图片文件新建文档。图片、项目可拖到标签栏空白处新建标签；图层拖入空白处时按变换后的实际边界创建画布，保留相对位置及独立蒙版。
- 中键拖动图层列表不会改变选择。拖动数值标签调整参数（Shift 精调、Ctrl 粗调、Escape 取消）；缩放工具支持拖动缩放，放大／缩小光标随方向即时变化。
- 保存快照期间可继续编辑和切换标签，后续修改仍标为未保存，不会把保存结果应用到错误文档。
- 视图 → CMYK 配置管理：枚举 Windows 系统配置和已导入配置，可选择、导入、删除非当前的导入副本；系统配置只读。
- 下载并校验更新后可选择“安装并重启”。原生更新助手等待编辑器退出，再替换软件包文件；检测到失败时回滚，并重新打开已保存项目。要求便携目录及父目录可写，不请求提权；保留旁边的恢复目录，不删除无关文件。更新前关闭其他实例。程序仍未签名。
- 新增文案覆盖八种语言，详见[0.5.3 发布说明](releases/0.5.3.md)。

**格式与往返注意：**含原生 16 位蒙版的非兼容保存使用 Windows v15，旧 Windows 版本会拒绝；兼容模式保持上游 v11–v14。复制项目时必须保留整个 .comp 文件夹（包括 windows 子目录）。上游重新保存可能丢弃 Windows 附加数据，无法保证这种往返仍保留原始 16 位样本，应保留 Windows 原件。

## 历史版本

以下章节记录各版本当时的能力与限制，不代表当前版本仍有同样缺项。

## 0.5.2 — HDR、印刷色彩与编辑工具

- 浮点 HDR 图层、单部件 RGB(A) EXR／Radiance RGBE 导入、保留超白高光的编辑与合成，以及 EXR 导出。HDR 使用 CPU 参考路径；整数图像保留已有 GPU 分流策略。
- 在“视图”加载 CMYK ICC 配置，可软打样、显示色域警告；支持 8 位 CMYK PSD/PSB 导入，以及嵌入配置的 CMYK JPEG／TIFF／PDF 导出。文档仍以 RGB 编辑，RGB TIFF 可保留整数精度。
- 新增可拖端点的线性／径向渐进模糊、高斯模糊保持透明度、模糊边界扩展、内容识别向外填充和平滑圆角；可单独转换图层的 8／16 位。
- RAW 新增 LibRaw 解码降噪、高光恢复、手动 Lensfun 畸变配置及直接进入 Camera Raw 的按钮。Camera Raw 参数预览以原图分辨率处理，不再先缩小源图。
- 新文案覆盖八种语言。验证及明确边界见 [0.5.2 发布说明](releases/0.5.2.md)。

**镜头校正边界：**需明确加载只包含一个匹配镜头的 Lensfun XML，按最接近的标定焦距校正；不是自动读取相机内嵌配置。不新增多部件／深度 EXR、32 位 PSD、PSD 导出、自动更新安装或代码签名。部分 macOS 交互差异仍存在。下方旧版本章节是历史记录。

## 0.5.1 — 同步上游 1.5.3

合并从 `3081719` 到 **`365b5745eda537f984f3d5bed1e53c361dbc9c91`（Compositor 1.5.3）**的全部 **58 个上游提交**，保留原始 Git 历史和 Windows 分支。

- 内容识别修复与填充更新为多尺度 PatchMatch，支持原生 8／16 位。16 位通过浮点工作区保留细分值，不先降成 8 位图像。
- Camera Raw 使用新的区域自适应阴影算法和系数，在正确的颜色处理阶段之间执行。启用该新阶段时整次请求走 CPU，等待匹配的 GPU 实现验证，不重新启用较慢的实验路线。其余 0.5.0 加速策略保留；每个 Camera Raw 分区可单独重置。
- 文件菜单新增“导入图像文件夹”，按名称导入当前目录中的受支持文件，不递归子目录。RAW 与分层 PSD 仍走原有导入流程；保留 HIF／HEIF 支持，更新上游应用图标。
- 读取支持范围内的 v12–v14 PNG 项目，即使原版没有写入 Windows 专用 `bitDepth` 字段也可识别位深；高位深资产将文档提升为 16 位，未修改的原始 PNG 字节保留。HDR／EXR 与平滑圆角形状会明确拒绝。仍按 8 位 v11、16 位 v12 保存。
- 文件夹相关新文案和支持版本范围同步八种语言。

**范围说明：**合入 Swift／Metal 源码不等于自动完成 Windows 功能移植。本补丁不新增 HDR／EXR、CMYK 软打样及导入／导出、渐进模糊、高斯模糊保持透明度、平滑圆角、新 macOS RAW 显影选项或原生分辨率 Metal Camera Raw 预览。验证与边界见[发布说明](releases/0.5.1.md)。程序仍未签名，更新仍手动安装。

## 0.5.0 — 性能整合正式版

- 整合 a1–a9 已验证的实现：GPU 预览缓存／脏区域合成、原生纹理显示、调整层／效果／适用滤镜，以及 8／16 位状态化液化和涂抹。复用源图和传输资源，未变化帧跳过处理；合适的大笔刷只在首次上传源图，后续鼠标移动保留笔画状态。
- 按端到端实测选择后端，而非强求全 GPU。普通画笔／橡皮／克隆／模糊、修复、透视、顺序亮度降噪、Atkinson／Floyd–Steinberg 使用 CPU。不超过 256 KiPixels 的独立动态模糊也走 CPU，避免传输开销；已驻留 GPU 的调整层不受影响。退役 GPU 编辑模块仅供回归测试，不再作为应用链接依赖；旧实验设置不能启用它们。
- 保留 CPU 参考预览、平移时的整图参考缓存和安全分块导出。默认导出仍为 CPU，GPU 导出需明确选择；硬件不支持、尺寸过大或预算不足时回退 CPU。
- 包含保持比例的对象选择和自愿开启的更新检查，下载验证大小及 SHA-256，稳定版只接收更新的稳定版本。仍手动安装；保留 8／16 位编辑、选区、撤销、八种语言和原 `.comp` 格式。
- 单一版本源统一界面／命令行、Windows 文件属性及便携包名称，打包时拒绝旧版本程序。**0.5.0 取代 0.4.0，成为稳定版 Latest。**

实测、验证和边界见 [0.5.0 发布说明](releases/0.5.0.md)。不承诺所有 GPU 都更快，也不宣称 GPU／Qt／Metal 逐像素完全一致。未提供正式证书，因此程序仍未签名；全局大图滤镜仍可能分配较大临时空间，未进行多设备人工认证。

## 0.4.1a9 — 状态化修饰与参考渲染流程（预发布）

- 液化采用累计位移从原图采样，涂抹携带刚混合的颜色。8／16 位共享 CPU／GPU 算法；合适的大笔刷保留 GPU 笔画资源，超过 8MP／预算时使用 CPU，最终回读仍同步。
- 画笔／橡皮／克隆／模糊笔刷／修复／透视的低收益 GPU 编辑入口已撤下。现有 GPU 滤镜／调整与原生显示保留；首选项可切换 CPU 参考预览。
- 平移未修改文档时复用全局调整预览；符合像素对齐条件的大图使用 CPU 分块导出，存在旋转等不安全条件时保留整图参考路径。
- 对象选择保持图像比例、对未命中点击重试局部推理，并排除透明像素；仍非 macOS Vision 等效实现。
- 帮助菜单可检查更新，启动检查需自愿开启；下载校验仓库地址、大小和 SHA-256。**仍手动安装，不自动覆盖。** 新文案覆盖八种语言，便携包带 Qt Network／Windows TLS。
- 未提供发行证书，**程序仍未签名**；提供显式证书签名脚本。GPU 边缘完全一致、自动安装、多设备人工交互认证仍未完成。

详见[发布说明](releases/0.4.1a9.md)。**仅预发布，Latest 保持 0.4.0。**下方为历史版本，包含已退役实验功能的记录。

## 0.4.1a8 — 减少 GPU 传输与中间准备开销（预发布）

- 图像修复的候选选择、细化与统计量留在 GPU，不再回读中间结果；最终只回读实际修改矩形一次，覆盖蒙版仅上传工作区域，顺序求解过程避免重复解绑／绑定资源。
- 画笔／橡皮／克隆／模糊直接上传原生 BGRA8／RGBA16 局部像素，回读行直接写入最终图像，去掉多余裁剪、格式转换与补丁复制。同批相同覆盖图仅上传一次；无选区、仅平移且亚像素位置精确相同的笔尖复用 Qt 覆盖，不近似小数位置。
- 本机新旧版本交替对比中，克隆笔刷入口的 8 位耗时下降约 41%，16 位约 49%。修复样本回读量减少约 92%，但总耗时未稳定改善。这些 GPU 编辑样本仍慢于 CPU，因此**实验性 GPU 编辑保持默认关闭**。
- 不是整笔画 GPU 常驻：仍保留最终一次同步回读和不可变 CPU 结果副本。没有新增设置、翻译、项目格式或运行时依赖。

**仅预发布，稳定版 Latest 保持 0.4.0。**详细计时与边界见[发布说明](releases/0.4.1a8.md)；以下为此前批次记录。

## 0.4.1a7 — GPU 编辑、变形、导出与原生显示（预发布）

- 新增普通画笔、橡皮、克隆、模糊笔刷、修复与透视变形的 Direct3D 11 处理路径，支持 8／16 位、选区及撤销。Qt 仍生成笔尖／选区覆盖，并用常量白色像素准备透视几何覆盖；启用“实验性 GPU 编辑”首选项后，GPU 负责图像采样、混合与求解。该首选项**默认关闭**，控制画笔、橡皮、克隆、模糊、修复和透视；当前预热实测比 CPU 参考路径更慢，因此只是评估开关，不代表提速保证。资源不足或不适合的请求保留 CPU 回退。
- 原生 Windows 画布可直接呈现 GPU 合成纹理，不再为该显示路径同步回读文档像素；图层图像／蒙版变换及混合在 GPU 完成，界面标尺等叠加仍由 Qt 绘制。离屏环境或失败时使用原参考画布。
- 原生显示和“导出为”渲染器选择不受该实验性编辑首选项控制。导出窗口新增渲染器选择：默认 CPU 参考结果，GPU 为明确选择。大图局部渲染支持分块；大型全局调整或非等比例变换等场景可能回退 CPU。PNG／JPEG／PDF 编码仍由 CPU 完成。
- 顺序亮度降噪与 Atkinson／Floyd–Steinberg 保留经性能验证的 CPU 路由。没有变更项目格式、运行时依赖或现有八种语言。

**仅预发布；Latest 保持 0.4.0。** GPU 不意味着所有工作在显卡执行、逐像素一致或所有场景更快；详细范围、验证及计时见[发布说明](releases/0.4.1a7.md)。

## 0.4.1a6 — GPU 液化／涂抹与传输资源复用（预发布）

- 为较大的液化／涂抹笔刷段加入 Direct3D 11 并行像素计算，支持 8／16 位。一个鼠标移动段的多个笔触按原顺序计算，只上传带采样边界的局部区域，处理后一次回读。
- 保留路径选区、柔边选区蒙版、图层／蒙版目标与撤销／重做。小范围操作、设备不可用或资源不足使用原 CPU 实现；没有将顺序亮度降噪／误差扩散重新强制改为 GPU。
- 滤镜、图层效果与液化／涂抹处理复用输入、打包输出和回读纹理；相同尺寸／位深的重复请求仍上传新像素并计算，不缓存过期结果。资源计入缓存预算并随清理释放。

**范围：**迁移的是 Windows 现有液化／涂抹像素算法，不是 macOS 的整笔画常驻纹理／累计位移场。Qt 显示仍需同步回读，画笔／橡皮／克隆／修复、透视变形、部分蒙版准备和导出尚未迁移。其余 a5/a5p1 限制继续适用；项目格式、依赖和八种界面语言不变。**仅预发布，稳定版 Latest 保持 0.4.0。**验证与实测见[发布说明](releases/0.4.1a6.md)。

## 0.4.1a5p1 — 顺序滤镜性能修复（预发布）

- Atkinson 与 Floyd–Steinberg 抖动恢复使用 CPU 参考实现，不再执行串行 GPU 调度；其余八种抖动样式保留 GPU 路径。
- 实际启用亮度降噪的 Camera Raw 请求整体使用 CPU，避免串行 GPU 计算及中间传输，保留参考像素结果。不启用亮度降噪、关闭“细节”、临时剪切预览和锐化蒙版预览仍可使用 GPU。
- 在初始化 GPU、上传数据或淘汰缓存之前完成路由。滤镜／Camera Raw 的预览与应用共用此策略，保留 8／16 位、选区及撤销／重做。没有新增设置、依赖或项目格式变更。

a5 的其他 GPU 功能及 Alpha 限制仍然适用。**仅预发布，稳定版 Latest 保持 0.4.0。**验证及计时见[补丁发布说明](releases/0.4.1a5p1.md)。下方章节为历史版本记录。

## 0.4.1a5 — GPU 滤镜、图层效果与 Camera Raw（预发布）

- 新增色相／饱和度（含范围与着色）、黑白、色彩平衡、渐变映射、添加杂色、颗粒和动态模糊的 GPU 预览。全部十二类调整支持 24 种混合模式，原有五类不再仅限 Normal。
- GPU 描边（内／外）、投影、内阴影、内／外发光与颜色叠加，支持蒙版、剪贴、组效果及不透明度。
- Camera Raw 图像处理阶段迁至 Direct3D 11：光线／颜色／校准、曲线、混色／点颜色、分级、纹理／清晰度／去朦胧／辉光／颗粒／暗角、光学、几何、降噪、锐化及剪切／蒙版预览。小型查找表、字体图集生成和 GPU 统计值汇总仍由 CPU 执行。
- 暗角、Bloom、十种抖动样式、色调对比、镜头校正和扫描线使用 GPU。滤镜预览、直接应用及 Camera Raw 预览／应用入口已接入，保留选区约束和撤销。

**Alpha 限制：**上述处理阶段已覆盖，但不保证与 CPU 逐像素相同或始终更快。Qt 与 GPU 的重采样和抗锯齿不同；测试中少量内描边角点的通道差异约 5% 以内。微小浮点差异可能触发 Hard Mix 或误差扩散的阈值变化。顺序亮度降噪／误差扩散在 GPU 上可能更慢。源图／蒙版准备、画笔／修复、界面分析和导出仍用 CPU；GPU 需同步回读，受临时纹理池及内存预算限制，超过 8MP 或资源不足回退 CPU。调整层 Hard Mix 要求硬件双精度。可用 `COMPOSITOR_DISABLE_GPU=1` 启用 CPU 参考路径。实时效果导出仍用参考渲染器；直接 GPU 编辑保存实际处理后的像素。项目格式和运行时依赖不变。**仅预发布**，稳定版 Latest 保持 **0.4.0**；验证及计时见[发布说明](releases/0.4.1a5.md)。

## 0.4.1a4 — GPU 色调调整层（预发布）

- 加速 **Normal（正常）混合模式的反相、曝光、色阶和曲线调整层**，支持 8／16 位、调整对话框预览，以及与高斯模糊、普通图层、蒙版、剪贴来源和组不透明度叠加。
- CPU 使用参考调整算法生成完整的逐通道查找表，再由 Direct3D 11 对图像逐像素应用。8 位使用 **256 项**，16 位使用 **65,536 项**，不会把高位深曲线降成 8 位查找。缓存的 Alpha 系数保留原生预览的反预乘行为。
- 修改源像素、蒙版或不透明度时复用查找表；调整参数变化只更新表，不重新上传源图或分配纹理；相同预览跳过计算和回读。
- 不含空间模糊的色调调整保留局部矩形合成与回读。调整参数／层序变化完整重算请求视口；含可见高斯模糊时仍需带边界扩展的完整请求区域计算。查找表资源计入缓存预算，不支持的文档或设备回退 CPU。

**范围：** 查找表生成、源图和蒙版准备仍在 CPU。本批加速预览图像处理，不迁移直接修改像素的滤镜应用、画笔、Camera Raw、其他调整／效果或导出。GPU 调整仅限上述 Normal 混合类型及 a3 的高斯模糊，仍为同步回读。首次生成／修改参数的查找表有成本，尤其是 16 位曲线，不保证所有操作均提速。项目格式、保存／导出像素、八种界面语言和运行时依赖不变。**仅发布为 Pre-release**，稳定版 Latest 保持 0.4.0。

## 0.4.1a3 — GPU 高斯模糊调整层（预发布）

- 在 Direct3D 11 上计算 **Normal（正常）混合模式的高斯模糊调整层**，支持 8／16 位以及多个模糊层与普通图层交错。六次横／纵整数盒式模糊保留 CPU 近似算法的边缘夹取与逐次截断；共享内存前缀和避免每个像素的工作量随半径线性增长。
- 调整结果支持图层蒙版、关联／独立蒙版位置、剪贴来源、祖先组蒙版及图层／组综合不透明度。蒙版覆盖率仍由 CPU 准备并缓存。非 Normal 模糊调整层、其他调整类型或实时图层效果保守回退 CPU。
- 只修改模糊半径时复用源图和覆盖纹理；相同预览跳过模糊与回读。两个可复用模糊临时纹理计入原有缓存预算，硬件／资源／预算不足时回退 CPU。

**范围：** 本批迁移高斯模糊的**预览计算**，不迁移直接修改像素的滤镜应用或导出。含可见模糊的变化预览因空间依赖而完整重算请求的视口／区域；仅含普通图层的预览继续使用 a2 局部矩形。蒙版／图层表面准备、画笔／修复内核、其他滤镜／Camera Raw、图层效果和导出仍使用 CPU。仍为同步回读，不是零拷贝显示。项目格式、八种语言及运行时依赖不变。**仅发布为 Pre-release**，稳定版 Latest 保持 0.4.0。

## 0.4.1a2 — 局部重合成与紧凑回读（预发布）

- 仅对准备后图层像素的变化包围矩形进行 GPU 重合成；区域内从透明背景重新混合所有可见图层，区域外保留已有结果。可见层序、显隐或混合模式变化时，保守地重算完整视口。
- GPU 将结果直接打包为原生 8 位 BGRA／16 位 RGBA 整数样本，仅将变化矩形复制到回读资源和 QImage，移除 CPU 对整幅浮点结果的逐像素转换。检查硬件格式支持，资源无法建立时回退 CPU。
- 蒙版／剪贴来源、关联／独立蒙版、变换、组不透明度和撤销／重做均依据实际表面差异，覆盖移动前后的区域。准备后像素完全相同的元数据／源图变化不触发计算与回读；已返回的旧预览保持不变。
- `COMPOSITOR_GPU_FULL_FRAME=1` 是诊断开关：保留源缓存与紧凑输出，但强制完整视口重合成／回读。`COMPOSITOR_DISABLE_GPU=1` 仍可切换为 CPU 参考渲染，原有缓存预算及淘汰控制继续生效。

**范围限制：** 本批加速预览合成与传输，不是画笔／滤镜编辑内核迁移。变化图层表面及差异仍由 CPU 准备；变化预览仍需同步 GPU 回读，旧帧被使用时可能复制整幅 CPU 图像；相距较远的改动合并为一个包围矩形，尚非稀疏分块。实时调整／效果及导出仍由 CPU 处理。没有零拷贝显示、项目格式变更或新运行时依赖，不保证所有硬件和操作均提速。本批及后续批次**仅发布为 Pre-release**，稳定版 Latest 保持 0.4.0。

- 已有文字层使用文字工具点击，`Ctrl+Enter` 应用行内编辑、`Esc` 取消；图层菜单 → 编辑文字可设置字体、颜色等。
- 调整菜单 → Camera Raw；曲线上点击增加点、右键删除中间点。颜色页点击预览拾取白平衡，点颜色页勾选拾取后点击图片。几何页开启引导后拖出最多两条线。
- 右键 Camera Raw 图表切换直方图/矢量示波器；Alt 拖动光线滑块查看裁切。预览提示不会写入最终图像。
- 空格拖动画布，Ctrl 滚轮缩放；`Ctrl+0` 适合画布，`Ctrl+1` 100%。
- `Ctrl+A` 全选，`Ctrl+D` 取消选区，`Ctrl+Shift+I` 反选；Shift 加选、Alt 减选。
- `Alt+Backspace` 前景填充，`Ctrl+Backspace` 背景填充，`Shift+F5` 内容识别填充。
- `Ctrl+G` 编组，`Ctrl+Shift+G` 取消编组，`Ctrl+E` 合并，`Ctrl+W` 关闭标签。首选项 → 快捷键可修改并应用。

## 兼容范围

读取支持范围内的 `.comp` version 1–15，包括 EXR 资产和平滑圆角；8 位、16 位、HDR、平滑圆角分别按所需的 v11／v12／v13／v14 保存。含原生 16 位蒙版时使用 v15；兼容模式保留上游可读的版本并附带独立版本化的无损蒙版数据。缺省时从 PNG 推断整数位深，HDR 图层保留浮点数据。未触碰的 PNG 字节及未知非渲染元数据保留。文字保留 fontRuns/colorRuns；Windows 缺少的字体可能替代，重新编辑会按 Windows 字体排版。像素滤镜/绘画/自由扭曲会栅格化文字和形状。选区与历史为会话状态。

PSD/PSB 支持 8 位及 16 位 RGB，以及通过嵌入或手动选定 ICC 配置转换的 8 位 CMYK；仍不支持 32 位 PSD。8／16 位图层使用整数 sRGB，HDR 图层使用浮点扩展范围 sRGB。Photoshop 智能对象、复杂路径/文字变形与部分效果保留栅格后备或给出转换报告，不承诺 Photoshop 所有结构都可继续编辑。导入不是 PSD 导出。
Camera Raw 对应本项目原版的功能，不是 Adobe 插件；镜头配置使用原版通用校正内核，不带 Adobe 相机/镜头数据库。
对象识别使用 Windows 本地模型，效果可能与 macOS Vision 不同；它对模型识别出的前景做连通区域选择，不能保证识别图中任意对象。
CPU／Direct3D 预览合成、字体、几何插值、模糊与发光边缘可能与 Metal 输出不同，不宣称逐像素一致。GPU 预览与 CPU 输出仍存在舍入及边缘采样差异。可选 CPU 参考预览及默认导出使用 CPU；GPU 导出需显式选择，直接编辑保存实际处理后的像素。启动前设置 `COMPOSITOR_DISABLE_GPU=1` 可禁用 GPU 预览。

画布最大单边 30,000px、总计 200MP；图像和蒙版分别最多 400MP，最多 10,000 层。实际像素预算随机器内存降低；大图滤镜需要更多内存和时间。保存使用暂存目录、摘要检查及恢复备份；目录替换不保证断电事务原子性。

需要 Visual Studio 2022 C++ / Windows SDK、CMake 3.24+、PowerShell 7、Qt 6.8.3 MSVC 2022 x64（Qt Image Formats 和 SVG）。

```powershell
pwsh -File ./windows/scripts/prepare-dependencies.ps1

pwsh -File ./windows/scripts/package.ps1 -QtDir C:/Qt/6.8.3/msvc2022_64 -SkipBuild
```

构建时由 CMake 将上游 Apple blocks 调度转换为 MSVC 并行循环，保留像素算法。上游 `CameraRawTables.bin` 更新后执行 `python windows/scripts/repack-camera-raw.py`；CMake 会检查原始文件哈希，拒绝使用过期资源。重打包只更换压缩格式，颜色表字节保持一致。

16 位 C++ 处理代码随源码提供，正常编译和程序运行不依赖 Python。修改对应算法后，开发者需运行 `python windows/scripts/generate-wide-pixels.py` 和 `python windows/scripts/generate-wide-processing.py` 重新生成；CMake 校验源码哈希，拒绝使用过期输出。这些生成脚本不会随便携应用发布。

首次准备依赖需要联网，后续运行不需要。vcpkg 提交、ONNX Runtime 1.22.1 和模型哈希固定在 dependencies.lock.json。构建运行 Qt Test；测试包括实际 PSD/PSB/DNG 解码、分层/文本/矢量、Camera Raw、液化手势及撤销、软选区、组效果与变换、主体模型、导入流程、外部重载、国际化与原有编辑回归。
fixtures 是自行生成的小型测试图；可从仓库根目录用 Python 执行 `windows/tests/generate_fixtures.py` 再生成。Python 不是应用运行依赖。
