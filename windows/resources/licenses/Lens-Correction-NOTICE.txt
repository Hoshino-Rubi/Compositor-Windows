RAW lens correction uses the dynamically linked Lensfun library (LGPL-3.0), GLib and their runtime dependencies. Their license notices are included alongside this file. The native DLLs may be replaced with compatible modified versions for debugging such modifications; no signature check or library lock prevents this.

The corresponding dependency sources and vcpkg build recipes are provided as the separate Compositor-0.5.3p1-lens-dependency-sources.zip release asset. The application build manifest, pinned dependencies and local build overlay are in the source repository. Lensfun calibration data has its own CC BY-SA 3.0 license; see Lensfun-Database-Source.md and the database license.
